# HC-028F Focused Playtest — All Built Region Composition Embodiment

## Goal
Play the existing built path normally and judge whether all eight places now feel like different physical sentences spoken by the same world, **without needing the HUD and without learning new controls**.

## Do not play to the beat
Do not count meter or intentionally time Pulse/Absorb/Stabilize. Composition is supposed to be perceived through pacing, bass/rhythm articulation, Core resonance and existing Host matter.

## Route
Use the normal route and/or the existing debug jumps to sample:
1. Surface Wake
2. Guide Threshold
3. Hub Chamber
4. Vascular
5. Silt
6. Grave
7. Comb Threshold
8. Aperture Fields arrival

## What each place should suggest
- **Surface:** soft receive → wake/expand → settle; buoyant and embryonic.
- **Guide:** brace → send intent → hold direction → receive reply; more directional than Surface.
- **Hub:** centered, cyclical and balanced; motion should feel like a junction/tonic rather than another route.
- **Vascular:** the established transmission/catch/receive/settle 4/4 voice remains the reference.
- **Silt:** gather/compress → brace → release; heavier and more particulate than Vascular.
- **Grave:** hold → draw → delayed return → settle; low, retained and memory-like.
- **Comb:** align/sort → sample → reject/pass; material should feel organized into filtering bands.
- **Aperture:** decompression and open exchange; broader and more spacious than chamber-scale regions.

## Acceptance
Pass if:
- every built region has an audible/kinetic identity without a new HUD dependency,
- Surface/Guide/Hub/Comb/Aperture no longer feel like they fall back to one generic Host breath,
- Vascular/Silt/Grave retain the identities already proven in HC028E,
- the same Pulse/Absorb/Stabilize controls still make sense everywhere,
- no region asks for beat-perfect input,
- traversal/movement feels unchanged in authority,
- the material response reads as world behavior rather than a particle effect pasted over the scene.

## Fail / report immediately if
- movement speed or steering appears rhythm-dependent outside the existing bounded Vascular presentation,
- a beat blocks a transition or route completion,
- ambient matter pushes the Core or changes collision,
- the five new regional voices make audio feel constantly busy or metronomic,
- Hub loses its centered/resting quality,
- Aperture's 12/8 reads as rapid ticking instead of broad field-scale groups,
- Comb's sorting motion overwhelms its existing threshold geometry.

## Best feedback
The most useful notes are simple comparisons such as:
- “Surface and Guide still feel the same.”
- “Hub now feels centered.”
- “Comb sounds different but the material does not.”
- “Aperture finally feels larger.”
- “Too much rhythmic ticking in ___.”
- “I stopped noticing the HUD and could tell where I was from pacing/sound.”
