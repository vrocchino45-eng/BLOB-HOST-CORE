# HC028A Focused Playtest — First Structured Session

Target: **8–10 minutes of normal play** on Golden Inquiry Baseline 01.

1. Start the build and use **F1** Playtest Trace.
2. Play naturally. Do not deliberately demonstrate every mechanic.
3. If *you* notice a moment that feels confusing, surprisingly clear, too fast, too slow, repetitive, or unusually interesting, press **Shift+M once**. Do not spam markers.
4. At the end press **Shift+T** to download the current session JSON.
5. Keep the JSON with the matching video.

## What we will compare

- video behavior vs structured action log;
- repeated sonar and resolution changes;
- movement with/without semantic change;
- Absorb/Stabilize hold duration and reserve effects;
- consequence → relationship → movement decisions;
- periods of semantic stagnation;
- Core snapshots across the session;
- manual markers against the telemetry context surrounding them.

## Acceptance target

The JSON should let us reconstruct the important gameplay story without reading the F1 HUD frame by frame. If it cannot, HC028A should be improved before HC028B adds an agent input harness.
