# HC028K Focused Playtest — Reciprocal Ecological Memory

## Goal
Verify that Tender/Watcher relationships continue to feel alive **after** a chord is released, without feeling like an affinity minigame or another progression gate.

## Test 1 — Tender retained receive
1. In Surface Wake, move within relationship range of the Tender.
2. Use **Stabilize + Absorb** long enough for the Tender to clearly read the gesture.
3. Release both inputs.
4. Watch the Tender for 5–10 seconds.

### Pass
- The Tender does not instantly return to generic idle.
- Its seed/frond/body response retains a quieter receive/care posture and decays naturally.
- There is no HUD score, bond meter or timing prompt.
- Nursery trust/bond logic behaves exactly as before.

## Test 2 — Same chord, Watcher
1. Move near the Watcher.
2. Use **Stabilize + Absorb**.
3. Release.

### Pass
- The Watcher answers differently from the Tender.
- Its sensing/light/ring language feels like a retained sample/record rather than care.
- The retained response lasts for several seconds and fades.

## Test 3 — Reciprocal exchange
Use **Pulse + Absorb** near each organism, then release.

### Pass
- Tender reads more like reciprocal/testing exchange.
- Watcher reads more like counter-sensing.
- The body continues answering briefly after release.
- No new gameplay power occurs.

## Test 4 — Noise rejection
Tap/churn random verb combinations very briefly near an organism.

### Pass
- Every accidental button twitch does **not** become persistent memory.
- There is no beat-timing requirement; a meaningful held relationship simply needs enough time to be perceptible.

## Test 5 — Bonded Tender cross-region continuity
If the existing Tender bond is earned, bring it into a later region and form/release a relationship chord.

### Pass
- Regional composition remains visible underneath the retained relationship response.
- The Tender still follows/repairs exactly as it did in HC028J.
- Relationship memory does not guide routes or alter traversal.

## Regression — Comb
Enter Comb from Hub, remain near the arrival seam, move deeper, return through the fold, then re-enter Comb.

### Pass
HC028I1 return arming/re-entry behavior remains unchanged.

## What to report
The most useful feedback is simply:
- "I could / could not tell the organism remembered what I just did."
- "Tender and Watcher did / did not feel meaningfully different."
- "The memory was too weak / about right / too visually busy."
