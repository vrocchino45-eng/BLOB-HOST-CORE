# HC-031C1 Focused Playtest

Use Grave II and rupture one object. Hold Absorb while looking through the released pieces.

Acceptance is simple:
1. At least one loose piece should become the retained relationship target quickly.
2. Holding Absorb should visibly pull and complete absorption on that piece.
3. After one piece is collected, another loose piece should be acquireable without leaving Grave.
4. Releasing Absorb should restore normal Grave targeting rather than keeping the fragment field forced.
5. It should be possible to collect some pieces while still naturally missing others that cool into residue.

A 5–8 minute test is enough for this correction; there is no need for a full 15-minute session unless something still feels wrong.
