# HC-031B Focused Playtest — Grave II Resonance Gameplay

Target: **12–15 minutes**. Do not force exact button combinations; this test is specifically checking whether Grave II behaves as one coupled place.

## Test
1. Reach Grave, return, then enter Grave II normally.
2. Confirm HC031A1 still makes the second visit spatially distinct.
3. Establish a relationship with **one** familiar Grave landmark and use Pulse. Watch the other Grave landmarks / witnesses rather than only the target. A secondary answer should be perceptible.
4. Try Absorb on a different landmark. The regional answer should redistribute differently from Pulse.
5. Use Stabilize while moving relationships among at least two landmarks. The region should gradually become more synchronized / less internally disagreeing.
6. Do **not** intentionally perform the old `cohere_draw → cohere_project → full_system` sequence. Grave II should still be able to resolve.
7. If a regional resolution forms, look for a brief synchronized response from the existing landmarks/witnesses. The debug/telemetry resolution may be `quiet_retention`, `shared_memory`, or `held_contradiction`.
8. Before resolving anything on one attempt, verify the normal Grave return fold still lets you leave. Resolution is progression credit, never an exit key.

## What matters
- Does touching one part of Grave cause another part to answer clearly enough to notice?
- Does the place start feeling like one system rather than three target objects?
- Does Stabilize feel like managing regional coherence rather than filling a hidden meter?
- Can you naturally discover different outcomes without a prescribed combo sequence?
- Is the answer readable without adding back visual clutter?

## Failure conditions
- Only the retained target visibly responds.
- Resolution still feels like an invisible button recipe.
- The regional response overwhelms HC030B1 visual hierarchy.
- The player can become trapped in Grave II.
- Grave II no longer feels spatially continuous with HC031A1.
