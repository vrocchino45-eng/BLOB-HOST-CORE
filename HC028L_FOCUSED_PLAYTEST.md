# HC028L Focused Playtest — Reciprocal Ecological Behavior

## Goal
Verify that an organism does not merely *remember* a relationship but lets that memory influence what it does next, without exposing affinity scores or changing progression.

## Test 1 — Bonded Tender: care memory changes spacing
1. Use the existing nursery path to earn the Tender bond.
2. Leave the nursery with the Tender.
3. Near the Tender, establish **Stabilize + Absorb** or **Pulse + Absorb** long enough for the relationship to be remembered.
4. Release the buttons and continue moving normally.

### Pass
- Tender keeps a noticeably closer / more attentive companion spacing for several seconds.
- It does not snap directly to the Core.
- It still stays visually separate from the Guide Orbiter.
- No route guidance, repair bonus or UI relationship score appears.

## Test 2 — Tender guarded memory
Create a guarded/cautious relationship memory, then release.

### Pass
- Tender gives slightly more space instead of continuing the exact same follow distance.
- The behavior decays back toward normal as memory fades.
- If the Core is actually strained, existing care behavior still takes priority.

## Test 3 — Watcher sample memory
1. In the nursery, use **Stabilize + Absorb** near the Watcher.
2. Release and move around it.

### Pass
- Watcher remains anchored in the same place.
- It holds attention on the Core/sample more persistently rather than immediately returning to generic tracking.
- It does not become a target marker or route guide.

## Test 4 — Watcher counter-sensing
Use **Pulse + Absorb** near the Watcher, then release.

### Pass
- The Watcher performs a restrained counter-scan while retaining its anchored role.
- This feels like a sensing organism answering remembered information, not an enemy wind-up.

## Test 5 — Memory decay
After either behavior, stop interacting for 10+ seconds.

### Pass
The organism naturally returns toward its existing baseline behavior. No permanent relationship state or hidden level remains.

## Regression — Tender repair
While bonded, increase Core scar/strain and compare care behavior.

### Pass
Existing strain attendance and repair remain dominant. HC028L spacing should not suppress care or increase repair rate.

## Regression — Comb
Hub → Comb → remain near arrival → move deeper → return → re-enter.

### Pass
HC028I1 re-entry/return arming remains unchanged.

## Best feedback
- "The Tender actually changed how it followed me / I couldn't tell."
- "The Watcher felt like it held or scanned remembered information / it just looked random."
- "The behavior felt organic / too scripted / too weak / too strong."
