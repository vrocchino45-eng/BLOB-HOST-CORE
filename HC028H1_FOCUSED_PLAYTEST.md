# HC-028H1 Focused Playtest — Topology-Conditioned Environmental Handling

## Goal
Determine whether the **same region** feels subtly different when the Core is rebuilt Deep-heavy versus Membrane-heavy, without making movement feel stat-driven or changing the controls.

## Recommended test
Use a region with a clearly readable current/pressure field, preferably **Vascular** first.

### 1. Establish baseline
Enter with the existing 1:1:1 arrangement if convenient. Move:

- with the current;
- across the current;
- against the current;
- vertically through an area where HC028G flow cues are visible.

This should remain very close to HC028G/HC028H movement.

### 2. Deep-heavy test
In Core Work, move all three retained pieces to Deep if available, then repeat the same movement.

Expected read:

- current feels slightly less able to grab/redirect the Core;
- the Core carries its own motion a little longer;
- HC028G lift/flow lines still truthfully show the applied environmental force;
- normal stick authority and top speed do not feel reduced.

Think **buffered diesel mass**, not “slow mode.”

### 3. Membrane-heavy test
Move all three pieces to Membrane and repeat.

Expected read:

- local flow takes hold a little faster;
- crossing a current should feel more exposed;
- letting go into the current should resolve toward local flow slightly faster;
- normal stick acceleration/top speed still feel like the same control system.

Think **race chassis exposed to the air**, not “fast mode.”

### 4. Inner-heavy / balanced sanity check
Inner-heavy should remain controlled and near baseline. 1:1:1 should be the most broadly neutral/adaptive read.

### 5. Region check
Try the same Deep vs Membrane contrast briefly in **Silt** or another region with a different force identity. The topology law should remain the same while the region supplies the force being received.

### 6. Hub regression
Return to Hub and select a destination normally:

`approach awake destination → A → guided flight → region`

There should be no topology-dependent obstruction or change to the guided flight.

## Acceptance
Pass if:

- Deep and Membrane are perceptibly different under environmental pressure;
- the difference is subtle enough that neither looks like a movement upgrade;
- 1:1:1 feels close to the pre-H1 baseline;
- stick acceleration, speed limit, boost and verbs feel unchanged;
- the lift-field visualization still matches what the Core is physically experiencing;
- no topology makes Hub/return progression harder.

## Fail conditions
Fail if:

- Deep simply feels slower;
- Membrane simply feels faster;
- one arrangement is obviously optimal everywhere;
- current response changes are large enough to disrupt established route timing;
- HC028G flow cues contradict the motion;
- Hub guided commit or convergence becomes topology-dependent.

## What not to judge yet
HC028H1 does **not** yet make verb output inherit topology character beyond the older HC027C physiology that already existed. The next pass should only deepen that connection if this environmental-handling layer feels natural.
