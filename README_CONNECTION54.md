## What changes

The Hub now explains whether the nearby route is dormant, still preparing, revealing its first invitation, or outside entry reach. If another destination is eligible, the instruction names it and its upper/middle/lower route band. Ready entry says A / E. If Stabilize is held, the instruction explains the existing requirement to release it before committing.

Optional Hub investigation no longer hides destination guidance after its readings are complete. A nearby movement-only return crease remains an explicit alternative rather than replacing the entry instruction. Core Work and in-flight passage receive their own instructions.

Only Hub investigation, Guide prompt selection, and the existing playtest HUD change in production. The candidate guards are shared with their explanation and match CONNECTION53 across 1,800 comparisons. No route is awakened, prepared, opened, teleported into, or granted progression by this feedback. The recorded first-entry failure was not reproduced in a live browser; this package addresses the demonstrated guidance gap and exposes its current readiness reason.
