Changed-files convergence update for the CONNECTION18 playable build. Historical HC/LS1 labels and reports remain indexed.

## Install

Extract this ZIP beside package.json in the existing BLOB-HOST-CORE folder:

```powershell
node .\APPLY_CONNECTION19.mjs --check
node .\APPLY_CONNECTION19.mjs --apply
```

Reload afterward. Exact originals are saved in CONNECTION19_BACKUP. Restore with `node .\APPLY_CONNECTION19.mjs --restore`. The installer refuses unknown baseline files or later edits rather than overwriting them.

## What changes

A Host-confirmed, positive Vascular membrane-load change from a verified Silt disturbance gets one short, localized pressure response at the first existing Vascular wall fold. That is the start of the existing tissue arrival wave. This is a signal consequence, not a grain arriving, material transfer, route completion or progression reward.

The sound uses two restrained procedural tones through the existing spatial world bus. The HC027D1 master, bus gains, attenuation, compressor and reference listening settings remain unchanged. No ambient music or broad mix adjustment is included.

The route publishes a read-only witness only after the existing Host confirmation returns a receipt. Its age is independent of later visual wave resets. Audio consumes each observed identity once. A duplicate callback, unlock/resume, return from Core Work or region revisit cannot replay it. Arrivals older than 0.5 simulation seconds are skipped; events occurring within 0.4 simulation seconds coalesce without queuing old sounds. Locked/suspended audio and Core Work consume the identity silently. Saturated signal reception alone does not create a new positive-effect witness.
