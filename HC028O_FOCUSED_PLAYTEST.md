# HC-028O Focused Playtest — Residue Recognition

## Goal
Prove that a completed ecological event can leave HC028N Host memory that a living organism later *reads differently according to its role*, without the residue becoming a key, reward, target, or movement command.

## 1. Tender care residue → Tender familiarity / Watcher sampling
1. In the nursery, create a safe Tender relationship (prefer Stabilize + Absorb or another relationship already producing care/reciprocity memory).
2. Release and let the HC028M1 immediate local response finish.
3. Wait for the HC028N residue to become the only remaining consequence.
4. Stay close enough that Tender and Watcher can be near the trace.

Expected:
- Tender body subtly opens/settles toward a familiar care read; seed-sac/glow may become a little more receptive.
- Watcher lens/pupil/sensors tighten into a restrained sampling read of the same care signature.
- Neither organism should move toward the trace because of HC028O.
- The residue should continue its normal HC028N decay and should not brighten/reset because it was noticed.

## 2. Watcher sample residue → Watcher verification / Tender caution
1. Create a Watcher sampling relationship (Stabilize + Absorb is the clearest first check).
2. Release and let immediate ecology end so a sample residue remains.

Expected:
- Watcher reads its own sample as verification: pupil/sensing bulbs become slightly more deliberate, not aggressive.
- Tender reads the same sensor trace more cautiously: guarding structures tighten slightly rather than opening as they do for care residue.
- No warning HUD, target lock, objective change or route response.

## 3. Counter-sensing residue
Use Pulse + Absorb near the Watcher, release, and wait for its counter-scan residue.

Expected:
- Watcher body produces a restrained compare/verify articulation.
- Tender should read it as caution rather than care.
- The effect should remain secondary to live Core verbs and normal regional motion.

## 4. Distance / fade check
Move both organisms (or yourself with bonded Tender) away from the residue's recognition radius, or simply wait through the HC028N fade.

Expected:
- Recognition disappears naturally with distance/decay.
- Fading residue produces a weaker read than retained residue.
- No new reciprocal memory is committed merely because an organism noticed residue.

## 5. Regression checks
- Hub deliberate route commit still works.
- Comb can be entered, not immediately kicked out, returned through, and re-entered.
- No `recipe is not defined` startup crash.
- Tender bond/repair behavior remains unchanged.
- Watcher remains nursery-anchored.
- P/A/S, movement, camera, chemistry and Core Work feel unchanged.

## Pass criterion
Without using debug text, you can reasonably read: **“this trace means something different to the Tender than it does to the Watcher”** while the trace itself remains passive and temporary.
