Optional inquiry counters remain historical observations and are never automatically completed. The old departure-prerequisite metadata and comparison wording are retired.

A route may still need its existing resource preparation; visiting other Hub bodies does not perform that work. Existing A/E commitment, Stabilize suppression, boundaries, movement, camera, world visibility, material ownership, growth, 3→6→12 progression and audio calibration remain under their existing owners.

CONNECTION54 addressed feedback. This pass changes the specific first-entry invitation prerequisite and removes remaining tour instructions.
