# CONNECTION58 — consolidated Hub review checkpoint

This single package collects CONNECTION54–57 over CONNECTION53. It accepts the recognized covered-file states from CONNECTION53 through CONNECTION57. Production gameplay and the executable bot catalog remain CONNECTION57; consolidation adds no gameplay behavior.

## Install

Extract into your existing project root, keeping CONNECTION58_PATCH intact:

```powershell
node .\APPLY_CONNECTION58.mjs --check
node .\APPLY_CONNECTION58.mjs
```

Reload after an upgrade. You may go directly from a supported checkpoint to this package without applying the intermediate installers. If CONNECTION57 is already fully installed, the installer recognizes that the consolidated payload is already present and leaves it unchanged.

The installer validates covered files, payloads and unchanged source/data anchors before writing. It recognizes Windows CRLF line endings, preserves unrelated files/history, and rejects unknown covered edits or unrecognized mixtures. Do not force an update over a rejection.

