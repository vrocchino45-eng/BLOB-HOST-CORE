## Instrumentation collision and corrected setup

An initial run installed the Stage2C observer after the existing BOT1D11C diagnostic recorder had wrapped the movement instance. That older wrapper retained the previously captured update method, bypassing the newer prototype observer. Stage2C therefore counted zero producer publications and flagged nine pairing issues even though the live runtime attached and released. This is invalid pairing instrumentation, not a demonstrated gameplay failure.

The corrected run prepended the existing Stage2C import to the served main.js response using the browser test runner before runtime creation. The source file on disk was untouched. This ensures older instance wrappers delegate through the already-observed method. The corrected run records producer publications and zero pairing errors. The earlier trace is retained as INITIAL_SETUP_COLLISION_TRACE.json with this qualification; do not use it as a gameplay regression result.
