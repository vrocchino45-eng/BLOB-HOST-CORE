## Purpose

HC-003A converts the completed HC-002 four-cell systems chain into a deliberate first playable minute plan.

This pass does not add a fifth cell or alter runtime gameplay. It defines what the opening should teach, what should remain optional, and what HC-003B should implement as the player-facing Guide/objective layer.

## Current Working Chain

```text
CELL_MEMBRANE_NURSERY_001
→ CELL_SCAR_FLOW_FOLD_001

```

## Design Decision

Selected opening structure:

```text
Option C
Membrane Nursery → Scar-Flow Fold → Signal Chorus Nerve
```

Bloom Residue Fork remains playable in the current chain, but it should be treated as the first beyond-minute fork rather than mandatory opening tutorial load.

## Why Option C

Option A, using all four cells as the first minute, risks making the opening too dense. Option B, ending after Scar-Flow, proves the no-gate tissue fold but does not reveal enough of the tonal/signal thesis. Option C gives the opening a clearer arc:

```text
awaken → nourish → respect scar → fold tissue → hear the host answer
```

That gives the player the first real experience of BLOB as growth, relation, tissue, memory, and tone without overloading them with the Bloom/Residue fork immediately.

## First Minute Player Understanding

By the end of the selected opening, the player should understand:

- I am the small core inside a living host structure.
- The world is not a room map; it is tissue and relation.
- Safe matter can be absorbed slowly through bond.
- Scarred matter should be listened to before taking.
- Pulse is not just an attack; it is a way to ask the tissue to answer.
- A morph is not a gate or teleport. It is the host changing state around me.
- Signal/tone is part of the world logic.

## Post-Minute Fork

Bloom Residue Fork should remain available after the Signal Chorus bridge, but it should not define the first-minute onboarding burden yet.

Player feeling for Bloom Residue:

```text
I crossed out of the first lesson and found the world can fork.
```
