# Package inspection report

- Package and candidate identity
- Snapshot manifest SHA-256
- Changed-file manifest and before/after SHA-256
- Method-level scope and forbidden-state checks
- Commands and exact exit status
- Focused and regression result links
- Controller capture, reproduction and matching telemetry
- Trade Inspector decision
- Experience Inspector decision
- Integration Inspector decision
- Exceptions, evidence and disposition
- As-built sheet and schedule updates

## Design and Canon Gate record

- Gap IDs, disposition and reviewed specification revision
- Owner blueprint link and approval reference, or existing requirement supporting the repair
- Explicit execution authorization, reviewer decision and closure evidence
- Remaining approved-versus-as-built variance and RFI links
