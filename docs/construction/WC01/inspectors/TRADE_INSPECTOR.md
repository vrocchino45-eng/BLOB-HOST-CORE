# Trade Inspector — WC01 v0.2

Examine one package in its isolated checkout and compare its file-hash manifest and diff against the admitted snapshot. Require each allowlisted production file to stay inside the work-order method scope. Verify no unapproved mutation, deletion, historical change, or shared source write. Independently rerun its focused tests. Require matched state evidence and the specified visual or behavioral capture. Reject on scope mismatch, unknown parity or missing evidence. Record decision and reasons in the handoff. Do not make fixes in another trade's files.

## Design and Canon Gate

Before reviewing a package, check its gap IDs, owning blueprint, release disposition and explicit execution authorization against the WC01 v0.2 Design and Canon Review. An allowlist limits file scope. It carries no construction authority. Reject a changed sub-scope whose decision or dependency is open.
