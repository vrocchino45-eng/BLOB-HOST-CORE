# HC-006B — Signal Chorus Layered Interaction Trigger Prototype

## Purpose

Prove a reusable BLOB interaction grammar deeper than “pulse once and register.” The player must establish relation through proximity, observation, timing, sustain, visible response, and release.

## Ownership

`SignalChorusLayeredInteractionSystem` owns the active trigger sequence after these locked prerequisites:

```text
SignalChorusReturnStateSystem complete
+ HC-005D combward pressure readable
+ HC-006A living tissue identity readable
```

The underlying return state remains intact. HC-006B owns only the layered interaction.

## Stage grammar

1. **Approach cadence knot** — proximity is read over time.
2. **Observe/read** — one pulse reveals the rhythm.
3. **Align with cadence** — two broad-window gold beats must be matched.
4. **Sustain resonance** — A/F is held; X remains an independent pulse.
5. **Release and settle** — holding prevents completion; release lets tissue remember.
6. **Complete** — interaction registers while route remains closed.

## Reuse target

After live verification, this grammar can guide future retrofits:

- replace single pulses with observation and timing where appropriate
- distinguish held relation from absorb
- make world response visible before numerical completion
- require release when the law being expressed is restraint or settling
