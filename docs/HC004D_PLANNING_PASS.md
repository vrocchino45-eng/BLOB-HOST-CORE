# HC-004D Planning Pass — Runtime Grave Morph Prototype

## Intent

HC-004D is the first carefully scoped runtime activation for the Grave Memory / Residue-Scar route.

The pass converts the HC-004A/HC-004B/HC-004C Grave route from planned/authored/renderable data into a **reachable prototype destination**, but only through the current morph architecture.

## Production Rule

Function maps across. Legacy runtime architecture does not.

The Grave route may become reachable only as a no-gate morph from the optional Bloom Residue Fork. It may not use old gates, doors, teleports, stage-node loaders, branch menus, old exit registries, or old chamber runtime.
