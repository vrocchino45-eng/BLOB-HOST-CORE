## Route

ROUTE_GRAVE_MEMORY_RESIDUE_SCAR_001

## Macro Cause

The Wounded Nursery Host protects new becoming but carries unmetabolized old scars. The Grave route is where the player first learns that remains are not simple resources.

## Anatomy Sources

| Anatomy | Role | Function |
|---|---|---|
| Residue Beds | Primary | break down remains and hold prior becoming attempts |
| Scar Fields | Primary | preserve injury and protect weak points |
| Marrow Interior | Secondary | stores inherited host identity and seed memory |
| Signal Choir Tissue | Supporting | lets old remains answer through pulse |
