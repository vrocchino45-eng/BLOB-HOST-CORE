# HC-003M — First-Minute Visual Readability Polish

## Purpose

HC-003M improves the readability of the current required first playable minute while preserving the Host Core Rebuild rules:

```text
local cells replace old chambers
morph tissue shifts replace exits
no hard gates / doors / teleports
every visible object remains recipe-driven
debug is not the final HUD
```

## Required Slice

```text
CELL_MEMBRANE_NURSERY_001
→ CELL_SCAR_FLOW_FOLD_001
→ CELL_SIGNAL_CHORUS_NERVE_001
```

## Optional Extension

```text
CELL_BLOOM_RESIDUE_FORK_001
```

Bloom Residue remains playable, but it is still the beyond-minute fork and not part of the required first-minute lock.

## Polish Targets

### Player Core

Goal: always read as the player, protected seed-core, and future-host potential.

Kept / reinforced:

```text
nested seed-core identity
persistent halo
vertical glint
inner embryo light
orbit motes
```

### Safe Seed

Goal: read as safe nourishment and future potential, not a generic pickup.

Changed:

```text
larger safe absorb ring
outer safe pulse ring
clearer warm pod glow
split shell remains readable
```

### Scar Contamination

Goal: read as old wound, unsafe to absorb, and resistant.

Changed:

```text
warning halo
jagged scar resistance teeth
clearer crack glow
scar memory motes retained
```

### Signal Bridge

Goal: become visually obvious when Signal Chorus asks the player to warm the bridge.

Changed:

```text
bridge action halo
focus beads
small confluence knot
clearer seed-signal thread span
```

### Guide

Goal: stay readable as interpreter while not blocking the active target.

Changed:

```text
guide offset adjusted farther from target center
scar/signal interpretation position shifted upward and sideways
path shimmer remains secondary
```

### Target Focus

Goal: target cue should read as organic relation/focus, not purely debug geometry.

Changed:

```text
slightly softer reticle opacity
slightly softer pointer-line opacity
selected halo remains readable but less harsh
```

## Non-Goals

HC-003M does not add:

```text
new cells
new morphs
route runtime
new mechanics
new abilities
combat
dialogue tree
quest log
old gates / exits / chamber runtime
```
