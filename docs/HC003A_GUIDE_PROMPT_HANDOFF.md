# HC-003A — Guide Prompt Handoff for HC-003B

## Purpose

HC-003B should replace debug-like instruction language with short world-facing Guide prompts.

The Guide should not become a full dialogue NPC yet. It is an interpreter and protective presence.

## Prompt Rules

```text
short
embodied
rare enough to breathe
only when useful
never a paragraph
never a quest menu
separate from debug text
```

## Draft Prompt Beats

### Awakening

```text
You are small. Stay near the warmth.
The lantern is watching. Move slowly.
```

### First Seed

```text
That seed is safe. Hold close and let it enter.
Do not rush the bond.
```

### Scar Warning

```text
That is scar. It remembers pressure. Do not eat it yet.
Listen with pulse before taking.
```

### First Fold

```text
The tissue is ready to fold.
Pulse when the wound answers.
```

### Scar-Flow

```text
This place is flow caught in scar.
Follow the pressure. Respect the clot.
```

### Signal Chorus

```text
The host is not silent.
This is not a path. It is an answer.
```

## HC-003B Forbidden Scope

```text
no dialogue trees
no branching conversations
no lore codex
no quest menu
no new cells
no new mechanics
```
