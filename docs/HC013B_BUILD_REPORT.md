# HC-013B Build Report — Comb Threshold Playable Proof

## Mode
Feature / Feel / Lock

## Purpose
Turn the dedicated Comb Threshold foundation into one continuous, recoverable synthesis challenge using only existing movement, Stabilize, and Pulse language. Completion may reveal the first field, but Aperture Fields must remain unmounted and non-crossable.

## Implemented

- Added `CombThresholdPlayableSystem` as one region-scoped gameplay owner for `comb_threshold`.
- Preserved `CombThresholdFoundationSystem` as the sole anatomy, visual-response, and bounded physical-feel owner.
- Authored `COMB_THRESHOLD_PLAYABLE_PROOF_HC013B` with six mixed filter bands.
- Each band requires the same combined posture:
  - centered movement preserves the Grave Memory line;
  - held Stabilize carries Silt Pressure through compression;
  - Pulse must occur inside the Vascular cadence opening.
- Added coherence as soft recoverable pressure rather than a health, death, or restart system.
- Off-center, unbraced, and off-beat attempts reduce coherence but cannot erase completed bands.
- Completed readings are retained irreversibly for the active run.
- Added one final centered Stabilize-and-Pulse synthesis after all six reads.
- Added a 2.2-second first-field reveal that dilates the existing eight-petal seal and expands the authored preview motes around fixed bases.
- Added visual response for active/completed teeth, filter lobes, seal dilation, and reveal progress without adding generic rings or trigger markers.
- Updated `ObjectiveSystem` to observe `comb_threshold_playable_synthesis` only after six reads, final synthesis, and witnessed reveal.
- Updated `GateSystem` to retain completion, read count, coherence/failure evidence, recovery evidence, and the first-field reveal in serializable route history.
- Preserved `apertureDestinationMounted`, `apertureGameplayReady`, and `apertureCrossable` as false before and after completion.
- Preserved the Gate-owned Comb return fold throughout the challenge.
- Added both Comb foundation and playable owners to hidden transition preparation; each initializes once without mounting, updating, or mutating progression.
- Added `ACT1_RUNTIME_PROFILE_HC013B` with an eight-system Comb active budget.
- Updated region, objective, package, browser, manifest, README, lock status, runtime guidance, and inherited validator lineage to HC-013B.
