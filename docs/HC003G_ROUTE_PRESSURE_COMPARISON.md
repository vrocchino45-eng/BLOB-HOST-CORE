# HC-003G — Route Pressure Comparison

## Selected route

### Grave Memory / Residue-Scar Route

**Status:** selected for next design branch, not runtime active.

**Strengths:**

- deepens Scar-Flow and Bloom Residue instead of bypassing them
- reinforces the Wounded Nursery Host conflict
- creates a natural role for Witness / Grave Listener style guidance later
- supports old core remains, residue shards, memory echoes, and inherited becoming
- keeps the first branch emotionally understandable

**Risks:**

- could become too somber if not balanced by wonder
- needs careful wording so residue does not feel like generic loot
- should avoid becoming a graveyard chamber remake with old gates

## Deferred route pressures

### Silt / Appetite / Pressure Route

**Status:** defer.

Good future branch for compression, hunger, and appetite, but it risks adding pressure traversal before the first meaning route is grounded.

### Vascular / Rhythm / Charge Route

**Status:** defer.

Strong future branch for rhythm, current riding, and charge, but it asks for more movement/timing systems before the memory foundation is stable.

### Bloom / Overgrowth Route

**Status:** defer after Grave Memory.

Bloom is already previewed through Bloom Residue Fork. It should become more dangerous after the player understands memory and residue cost.
