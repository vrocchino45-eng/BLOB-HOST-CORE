# HC-010F Build Report

## Outcome

HC-010F locks the four objects that teach the Grave Memory circuit as readable landmarks. It replaces their expired proxy contracts with four distinct procedural anatomies and lets their existing verbs change those anatomies visibly. It does not change the route circuit or expand the world.

## Build strategy

- **Mode:** bounded visual-convergence successor to the live-accepted HC-010E route.
- **Purpose:** make husk, silt, scar, and seed identifiable before the prompt names them, and make Pulse, Stabilize, and risk visibly legible on those bodies.
- **Allowed:** existing procedural geometry, materials, local animation, F1 diagnostics, recipe lock metadata, and focused regression coverage.
- **Forbidden:** new routes, cells, entities, abilities, objectives, gates, classes, registered systems, interaction-range changes, object relocation, or progression mutation.
- **Locked:** Gate-owned entry/return, HC-010D region-local movement boundary, HC-010E consequence sequence and Hub composition, first-slice budgets, and dormant archive isolation.
- **Deleted/disabled:** exactly four active Grave placeholder states; their records remain as inactive historical contracts. Permanent landmark-defining rings remain disabled.

## Visual and feel targets

| Landmark | Required read | State response |
| --- | --- | --- |
| Old Core husk | Collapsed prior life; protected remains | Failed asymmetric breath, scar-crack answer, brief Pulse/risk echo |
| Memory silt | Settling trace; stabilizable, not food | Falling ash, counter-turning voids, strands align under Stabilize |
| Protective scar | Low guard tissue; not a gate | Delayed crack light and recoil teeth only during greedy risk |
| Inheritance seed | Sleeping future potential; protected | Contained upright pulse inside residue nest and memory skin |

`ChemObjectVisualComposer` owns the four bodies. `GraveMemoryRouteSystem` owns their Pulse, stabilization, and risk motion. Neither owner may mutate route truth.

## Measured proof

- Four distinct semantic roles, silhouettes, and motion languages.
- Procedural part counts: husk `19`, silt `43`, scar `21`, seed `15`.
- All four source placeholders inactive and non-expired under HC-010F.
- Husk and silt memory echoes appear only as transient responses.
- Stabilization aligns silt strands while ash continues downward motion.
- Unsafe Absorb exposes scar recoil teeth without consuming remains.
- Interaction ranges remain Pulse `2.2`, Stabilize `1.8`, safe transfer `1.8`.
- Active budgets remain `15 → 13 → 8 → 7`; dormant compatibility count remains `20`.

## Acceptance and regression gates

1. Compose the real runtime recipes and reject fallback geometry or active placeholder state.
2. Measure distinct landmark silhouettes and required anatomy-part families.
3. Exercise Pulse, Stabilize, and unsafe Absorb responses adversarially.
4. Reject permanent object-defining rings, consumption, completion, or ownership mutation.
5. Invoke both F1 text paths and require `LOCKED 4/4 expired:0` with no nonfatal error.
6. Retain HC-010E consequence/Hub proof, HC-010D approach proof, HC-010C prompt/screen truth, HC-010B circuit proof, the complete first-slice lineage, production compilation, and served-output identity.
