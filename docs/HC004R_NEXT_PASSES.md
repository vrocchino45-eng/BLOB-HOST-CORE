# HC-004R Next Pass

## Recommended

### HC-005A — First Route Return Continuity Planning

## Purpose

Plan how a completed first-reading route returns toward the route-awareness function without restoring the legacy Hub/chamber/exit architecture.

## Planning questions

- What tissue process carries the core away from the settled Grave bed?
- Does the return reconnect directly to Signal Chorus or to a short intermediary fold?
- What makes the return readable without a gate marker?
- Which system owns the transition?
- How is the completed Grave state preserved after leaving?
- How does the route prepare Comb Threshold without implementing it yet?

## Allowed

- authored return-continuity plan
- ownership map
- no-gate visual language
- return trigger requirements
- camera and movement target
- acceptance and regression tests

## Forbidden

- runtime return implementation
- literal Hub room
- teleport
- door or gate
- old exit registry
- branch menu
- Comb Threshold runtime
- Aperture Fields runtime
- new combat or ecology
