# HC-003A — Opening Flow Spec

## Opening Flow Target

```text
1. Wake inside Membrane Nursery.
2. Learn player-core movement.
3. Target safe seed.
4. Hold absorb and complete first nourishment.
5. Learn scar caution.
6. Pulse to let tissue fold.
7. Arrive in Scar-Flow.
8. Read memory/pressure/clot logic.
9. Reach Signal Chorus.
10. Hear the host answer.
11. Leave Bloom Residue Fork as optional beyond-minute continuation.
```

## Timing Target

```text
0–10s: player sees core, Guide, and tissue scale
10–20s: player finds safe seed
20–35s: absorb completes
35–50s: scar warning / first pulse
50–75s: first no-gate fold to Scar-Flow
75–110s: Signal Chorus reveal / host answer
after 110s: optional Bloom Residue Fork continuation
```

## Required Actions

```text
move
look / keep core visible
target
hold absorb
pulse
follow target focus
respect unsafe matter
```

## Not Required In First Minute

```text
full Bloom Residue stabilization
crafting
combat
dialogue choices
faction/caste logic
relic inventory
boss pressure
Act 2 field navigation
Strand B inversion
```
