# HC022C — Micro-Interaction Response Memory

## Purpose
Move optional micro-play from 'a thing reacted' toward 'I understand what this family does when I use this verb.'

The six existing micro-ecology families now retain lightweight recognition of the four-verb vocabulary:
Scan / Pulse / Stabilize / Absorb.

The system records the most recent family + verb + physical result and tracks whether that relationship has been encountered before. This is NOT a checklist, collectible, objective, XP system, or completion requirement. Its purpose is to let repeated interactions become predictable and therefore intentional.

Examples:
- Pulse on current-riders: disturbance occurs, then flow reclaims them.
- Stabilize on sorting grains: density bands resolve.
- Absorb on spores: the pull displaces the local ecology.
- Scan on echo motes: identifies a delayed response pattern before acting.

## Performance
No mote-count increase (66), no new world objects, geometry, particle system, raycast loop, or second ecology pass.
Relationship memory is six bytes in a fixed Uint8Array and updates inside the existing ambient loop/result path.
