# HC017D — Region-Specific Material Behavior

HC017C's fixed 42-mote ambient field remains the sole micro-material population.
This pass changes only how that same field moves/responds according to existing route/cell state.

- Grave: heavier residue; stronger damping/downward bias; Pulse/Absorb are more reluctant; Stabilize settles it readily.
- Vascular: freer suspension with persistent directional flow; material carries through the space and resists being completely held.
- Silt: sediment-like drift; Pulse produces the strongest scatter and Absorb draws particulate somewhat more readily.
- Other Host spaces: retain the calmer HC017C-style suspension baseline.

No particles grant inventory, chemistry, growth, route progress, gate progress, or objectives.
Particle count remains fixed at 42. Existing route systems and verb systems are not modified.
