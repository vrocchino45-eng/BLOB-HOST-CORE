# HC020B — Readable Verb Grammar / Anti-Mash

## Evidence
Based on the HC020A 5:53 playthrough. The busiest interaction sequences clearly communicate that
"something is happening," but do not consistently communicate why one verb is the sensible choice.

## Guide Threshold test grammar
- Pulse = interrogate/read the living current.
- Stabilize = sustained commitment that visibly organizes turbulent material.
- Absorb = not a valid answer for raw living flow; the material visibly recoils/rejects the attempt.

The pressure bodies themselves now carry more of the state:
unread/ambiguous -> Pulse-read turbulent -> progressively coherent under Stabilize -> calm current.

Wrong Absorb use produces a fast visible recoil instead of silence. Stabilize requires sustained
coupling; rapid cycling does not replace the hold.

## VFX hierarchy
Guide publishes a suppression signal so the large generic Stabilize lattice is reduced there.
The material being stabilized is intended to become the main feedback.

## UI progression cleanup
Opening the Status / Info page is no longer a Hub objective or progression prerequisite.
Hub completion now comes from world-space foundation readability + the completed Hub investigation.
The Status page remains optional reference UI and input routing only.

## Documentation hygiene
74 inherited historical HC reports were moved out of the project root into:
`docs/build_history/`

The root now keeps active operational docs plus this current report.

## Locked
No world expansion. Surface Wake, boundary/crossing authority, movement, camera, chemistry,
BondSystem, ChemObjectSystem and the ambient field remain unchanged.

## HC020B acceptance test
After the first readable encounter, the player should begin to see turbulent current and think
"Stabilize" rather than "which button does this object want?"

A wrong verb must answer quickly enough to revise the hypothesis rather than invite button cycling.
