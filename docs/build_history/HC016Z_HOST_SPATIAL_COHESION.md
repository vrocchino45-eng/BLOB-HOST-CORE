# HC016Z — Host Spatial Cohesion

## Mode
CONVERGENCE / PRESENTATION / NO NEW GAMEPLAY SYSTEM

## Purpose
HC016Y made route movement continuously different. HC016Z makes the route volume itself communicate those differences so Grave, Vascular, and Silt read as living Host anatomy rather than gameplay assemblies placed in empty space.

## Changes
- Grave: adds low-cost continuous memory strata through the traversable bed. The existing landmarks, chemistry, return fold, and physical feel remain authoritative.
- Vascular: adds repeated asymmetric membrane folds along the existing vessel curve. These visually organize circulation without becoming valves, targets, or triggers.
- Silt: adds irregular residue banks along the existing path. Banks tighten entry/deep sections and deliberately recede through the porous relief pocket.

All additions are presentation-only, targeting-suppressed geometry created once at route initialization. No per-frame geometry allocation or new interaction ownership was added.

## Acceptance
1. Grave reads as layered residue/memory terrain across the journey, not only at its authored objects.
2. Vascular reads as travel inside a structured living conduit; its gameplay valves remain visually distinct.
3. Silt visibly communicates tight → porous relief → tight/deep pressure before HUD explanation.
4. New anatomy cannot be targeted or interacted with.
5. Movement and route completion remain unchanged from HC016Y.
6. Tight and normal cameras remain smooth; no new per-frame geometry work exists.

## Deferred intentionally
Verb physicalization, ambient micro-material, and chemistry coupling are retained as the next experiential layer after spatial cohesion is accepted. HC016Z does not introduce them.
