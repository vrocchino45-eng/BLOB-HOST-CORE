# HC022B — Micro-Interaction Verb Readability

Interact/Scan is restored as a first-class verb in optional micro-play.

- Interact / Scan = understand without mutating.
- Pulse = disturb / reveal / communicate.
- Stabilize = organize / synchronize.
- Absorb = incorporate / remove / commit.

Scan reads the nearest local micro-ecology family and exposes a short-lived physical finding rather than a required button instruction. It has no objective/progression authority.

Performance remains constrained: 66 motes, no new particle system or geometry, no second ecology pass, and no new raycast loop. Scan detection is collected inside the already-existing mote update loop.

HC022A Y-inspection intent behavior and HC022A1 runtime fixes remain locked.
