# HC021C — Primitive Core & Anatomical Growth Foundation

## Mode
Implementation / convergence.

## Purpose
Create visual headroom for BLOB's micro-to-macro evolution without changing the working gameplay body.

## Anatomical chronology
- Awakening: membrane + nucleus. The Core is deliberately proto-cellular.
- Surface: membrane differentiation becomes visible.
- Guide: an internal directional/locomotor organization emerges.
- First Hub arrival: those structures organize into a visibly young Core.
- Grave: retention / memory anatomy.
- Vascular: circulation / transport anatomy.
- Silt: filtration / boundary anatomy.
- All three retained: an integrated anatomical foundation for later evolution.

The existing Grave pearl/ligament, Vascular filament/cadence, and Silt pressure adaptation are preserved and reclassified as actual anatomical contributions rather than route badges.

## Hard locks
Collision and interaction footprint, movement, camera, verbs, targeting, chemistry, gates, route completion, and region geometry are unchanged.

## Future rule
Complexity must be earned visibly. Future regions should modify, specialize, deform, connect, or reorganize existing anatomy before simply attaching another decorative layer.

## Acceptance
The opening Core should look dramatically more primitive than the current late first-slice Core. By Hub it should already look anatomically more organized. Each of Grave/Vascular/Silt must leave a visually distinct retained structure, and the three together must read as the beginning of an organism rather than three unlock icons.
