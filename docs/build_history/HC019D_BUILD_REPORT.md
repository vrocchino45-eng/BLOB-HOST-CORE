# HC019D — Continuous Interaction Field

## Mode
CONVERGENCE / MICRO-INTERACTION CONTINUITY.

## Purpose
Reduce the empty space between authored Surface Wake interactions without adding a new mechanic.

The project already had a low-cost AmbientMaterialInteractionSystem. HC019D extends that existing
system instead of creating another particle layer.

## Changes
- Ambient host motes: 42 -> 54.
- Surface Wake gets a living-suspension profile.
- Pulse, Absorb and Stabilize responses leave ~3 seconds of local visual/physical memory.
- Recycled motes preferentially repopulate slightly ahead of player travel, so movement continues
  to encounter responsive material rather than leaving all micro-material behind.
- Nearby responsive density and remembered responses are exposed in debug telemetry.

## Verb response
- Pulse: scatters the field; disturbed motes retain dispersal memory.
- Absorb: compatible motes draw toward/bank around the Core and retain a short orbit response.
- Stabilize: nearby motes organize and remain calmer after the button is released.

## Explicit non-authority
These motes do not grant chemistry, inventory, growth, objective credit, route completion or
crossing permission. They are the low-stakes connective tissue between authored material problems.

## Locked
Surface Wake HC019B/C gameplay, Listening Fold logic, boundary crossing, Guide Threshold,
movement, camera, chemistry, Bond/ChemObject, and generic verb rules.

## Acceptance
Walking between authored objects should no longer feel visually inert. The same three verbs
should produce immediate, readable micro-responses during ordinary traversal without creating
another task or objective.
