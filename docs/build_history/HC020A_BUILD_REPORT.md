# HC020A — Density & Attachment Baseline

## Mode
AUDIT / BASELINE. No gameplay behavior is changed.

## Milestone
Surface Wake -> Guide Threshold -> Hub Chamber must become one continuous, enjoyable first journey
before BLOB expands into more stages.

## Two loops now being measured

### Skill
Teach -> Repeat -> Vary -> Combine -> Subvert -> Master

The same verb/material rules should recur enough for the player to recognize them. Density does
not mean a new bespoke interaction every few meters.

### Attachment
Toy -> Mystery -> Consequence -> Memory -> Becoming

The Core, Orbiter, entities and host should retain evidence of play so the player begins to care
about what this organism becomes.

## Additional constraints
- Choice: not every interaction should collapse to one designer-approved verb.
- Failure: prefer a recoverable changed situation over reset/not-yet-success.
- Contrast: dense interaction needs quiet and observation space.
- World initiative: host/entities should sometimes act first.
- Delayed payoff: early mysteries should gain meaning later.
- Spectacle: occasional punctuation, not constant noise.
- 10-second identity: Core + Orbiter + enormous host + living matter + physical verbs.

## Density rule
Increase meaning and relationships per object, interaction and minute. Do not equate density with
more objects, particles, objectives or systems.

## Build rule
No new major system unless existing systems fundamentally cannot produce the desired experience.
A proposed HC020 change should strengthen at least two design dimensions.
