# HC018A — Interaction Composition / Readability

Derived from the full HC017E playthrough.

This pass does not change interaction mechanics. It establishes a presentation hierarchy:
anatomy -> target -> verb response -> environmental consequence -> anatomy.

Changes:
- small camera breathing-room pullback around existing interaction truth;
- Guide and bonded Tender yield away from the Core/target composition during interaction;
- ambient micro-material opacity reduces while an authored interaction is visually dominant;
- residual non-active verb effects receive restrained suppression;
- all presentation changes release rapidly after interaction so anatomy becomes dominant again.

Locked:
- interaction ranges and target selection;
- BondSystem and ChemObjectSystem;
- InspectionCameraSystem;
- movement;
- route progression;
- chemistry;
- gates/transitions;
- Core scale.

Acceptance target:
With debug HUD ignored/hidden, a nearby interaction should more clearly read as
Core -> target -> action -> response rather than multiple equal-weight visual signals.
