## Mode
IMPLEMENTATION / SPATIAL EXPANSION ONLY

## Purpose
Turn Silt from a short tube containing several nearly adjacent mechanics into a
route whose compression, brace, appetite choice, deep consequence and return are
physically separated.

## Measured change
- Previous authored Silt path: 7.45 world units
- Expanded authored Silt path: 24.20 world units
- Previous movement radii: [4.45, 3.05, 6.6]
- Expanded movement radii: [6.8, 4.25, 21.2]
- Core scale changed: NO

## Spatial grammar
Hub departure / return throat
→ compressed pressure-reading approach
→ rib-brace corridor
→ widening porous-choice pocket
→ recompressed deep passage
→ deep pressure-release organ
→ reversed Silt breath
→ return fold.

Unlike Grave, Silt is not broad and sparse throughout.
Unlike Vascular, Silt is not one long readable current.
Its identity is **tight → open decision pocket → tight/deep → release**.

## Gameplay contract preserved
The existing sequence remains:
1. Pulse to read pressure.
2. Stabilize to brace/release living ribs.
3. Selectively Absorb porous nourishment.
4. Packed residue remains dangerous but recoverable.
5. Reach deep enough with settled compression.
6. Release pressure and form the existing return fold.

No interaction range, required hold duration, failure rule, completion requirement,
route owner, crossing owner, chemistry rule, ability or objective owner was changed.

## Presentation
The TubeGeometry now has enough longitudinal segmentation for the longer curved
passage. Appetite packets and the deep pressure organ are modestly enlarged so
they remain readable at the expanded spatial scale.
