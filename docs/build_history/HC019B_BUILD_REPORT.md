# HC019B — Surface Matter-State Passage

## Mode
CONVERSION — one obstacle only.

## Why Surface Wake
The HC019A audit showed that the earliest living-nursery circuit already has the right raw
ingredients: Pulse reads matter, Stabilize filters/changes it, safe Absorb or clean delivery
produces a successful physical outcome, and the Listening Fold appears afterward.

Previously the causal link was represented primarily by `agencyProven -> foldInvitation`.
HC019B converts that into an explicit world state.

## New causal chain
Pulse reads the carried matter
→ existing Stabilize / safe Absorb changes or safely resolves it
→ a safe player-authored material result is produced
→ the Surface membrane passage opens physically
→ existing Listening Fold sees `foldInvitation`
→ the existing layered fold interaction continues unchanged
→ existing boundary/crossing authority remains unchanged

## Physical consequence
When `materialPassageOpen` becomes true:
- Surface pressure eases slightly;
- flow biases toward the already-authored Listening Fold;
- the existing pressure-front anatomy visibly parts and thins;
- the changed passage remains open.

## What was NOT changed
- SurfaceWakeLayeredInteractionSystem
- LocalCellBoundaryMorphSystem
- Guide Threshold logic
- movement controller
- camera system
- BondSystem/ChemObjectSystem
- verb input/ranges
- chemistry inventory
- crossing ownership

This is deliberately one obstacle, not a global rewrite.

## Acceptance
The first obstacle should now read as:
`understand matter -> change matter -> see passage open -> approach the newly available fold`,
not `perform actions until a hidden flag enables the next object`.
