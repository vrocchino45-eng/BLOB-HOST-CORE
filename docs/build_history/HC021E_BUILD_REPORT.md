# HC021E — Consequence & Core Memory

## Mode
Implementation / convergence.

## Purpose
Make a player's already-working mechanical decisions leave visible bodily memory without adding a new progression currency or ability system.

## Surface memory traces
The first meaningful player-authored nursery consequence writes one subtle trace into the young Core:
- Filtered unsafe matter before commitment -> **filtering care trace**: smoother/differentiated mantle behavior.
- Absorbed unresolved contamination -> **scar tolerance trace**: slight persistent shell asymmetry/tension.
- Committed clean matter without filtering -> **nutrient binding trace**: stronger nucleus-binding pulse.

These are not classes, bonuses, gates or abilities. They are visible history.

## Route anatomy
The existing Grave / Vascular / Silt retained structures remain the larger anatomical memories:
retention-memory / circulation-transport / filtration-boundary.

The long-term rule is now explicit: early subtle traces are written into the primitive body, while later region anatomy modifies and interconnects that body.
