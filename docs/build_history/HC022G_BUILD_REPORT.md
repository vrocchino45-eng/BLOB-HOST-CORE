# HC022G — Regional Host Rhythm Interpretation

## Purpose
Make the Host rhythm visibly belong to the larger anatomy, not only the ambient motes.

All regions sample the single HC022F Host signal. No independent heartbeat timers are introduced.

## Regional interpretation
- Grave: delayed, heavy compression through the residue bed.
- Vascular: a traveling surge through existing vessel/fold tissue.
- Silt: lagged compression/settling through envelope, ribs and deep organ.
- Guide remains coupled to the same Host signal where its current presentation allows it.

The regions do not pulse identically. They are tissues of one Host responding according to their physical role.

## Performance and gameplay locks
No new geometry, draw call, particle system, collision, gameplay current, interaction range, objective, gate, chemistry, or progression authority.
Existing meshes/materials are modulated after their own route animation using the shared scalar Host phase.

## Target
Standing still in different regions should make the same Host cycle visible, but not visually identical.
