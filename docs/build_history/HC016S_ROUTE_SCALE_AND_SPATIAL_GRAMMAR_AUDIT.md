## Scale decision
**Do not shrink the Core.**

The Core is the scale reference for the Host. Route geometry should grow around it.

This phase will also avoid a naive uniform scale-up. The goal is additional *journey*: approach space, readable landmarks, gameplay field, consequence space, and return distance.
