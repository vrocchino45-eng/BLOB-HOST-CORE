# HC021B — Ambient Matter Ecology

## Mode
Implementation / convergence.

## Purpose
Make the spaces between authored encounters answer the verbs the player already knows.

## Scope
The existing AmbientMaterialInteractionSystem is elaborated instead of adding another mechanic/system. Its motes now form four low-cost behavioral families: suspension, current-riders, settling residue, and reactive spores.

Regional rhythm comes from existing spaces:
- Surface: living suspension.
- Grave: settling residue.
- Vascular: current-riders.
- Silt: particulate beds.
- Other host space: neutral suspension.

Pulse scatters them, Stabilize organizes/calms them, Absorb only draws the already-compatible subset. Recent responses persist briefly as physical memory.

## Forbidden
No inventory rewards, chemistry mutation, objective progress, gates, route authority, Core growth, new verb, new region, or authored-object relocation.

## Acceptance
Traversal should feel inhabited even between objectives. A player should be able to press a known verb in ordinary space and see a consistent material answer without creating collectible clutter or a new task layer.
