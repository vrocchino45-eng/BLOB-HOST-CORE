# HC022D — Micro-Interaction Rhythm Chains

## Purpose
Let the player discover that learned verbs can be intentionally sequenced on the same local ecology.

Supported optional rhythms:
- Pulse -> Stabilize
- Stabilize -> Pulse
- Stabilize -> Absorb
- Pulse -> Absorb

The result depends on the ecology family. Example: Pulse then Stabilize can scatter spores and then let them reform coherently; Stabilize then Pulse can make an ordered current carry a disturbance farther; Stabilize then Absorb can make sorted grains yield a more selective draw.

This is not a combo meter. There are no points, required chains, objectives, or progression gates. A chain only registers when two distinct verb edges affect the same nearby family inside a short window. Holding a button cannot repeatedly trigger it.

## Performance
Still 66 motes. No new world object, particle system, geometry, raycast, ecology pass, or dynamic relationship array. Chain state uses scalar fields and reuses the existing response path.

## Why
HC022B established Scan -> hypothesis. HC022C established repeated verb/family prediction. HC022D adds a small next layer: **cause -> response -> deliberate second action -> transformed response**.
