# HC-002L — Runtime Second Morph Prototype

## Purpose

Activates the second no-gate local-cell morph:

```text
CELL_SCAR_FLOW_FOLD_001
→ CELL_SIGNAL_CHORUS_NERVE_001
```

This remains a tissue/perception fold, not a door, gate, or teleport.

## Runtime Flow

1. Complete the first morph into Scar-Flow.
2. Stabilize the Scar-Flow interaction loop.
3. When Scar-Flow is stable, pulse the listening/path focus.
4. The Signal Chorus Nerve fades in while Scar-Flow fades back.
5. Player remains in continuous control.
6. Active cell becomes `CELL_SIGNAL_CHORUS_NERVE_001`.
