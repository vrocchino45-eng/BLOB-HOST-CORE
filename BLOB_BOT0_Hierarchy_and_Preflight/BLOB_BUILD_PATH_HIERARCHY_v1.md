## North star — a causal living Host, not parallel demos
**Core acts → relationship/target accepts or refuses → regional material/physiology responds → Host records only authenticated consequences → Guide/HUD truthfully interprets the state → Core and world retain consequences.**

### One hierarchy, two different kinds of proof
**Ownership/conservation proof** answers whether the numbers and receipts can be trusted. **Experience proof** answers whether a player can find, understand, and use those relationships under normal camera and controls. Neither substitutes for the other.

### Labels for work status
- **VERIFIED** = an owner reported accepted state in REC1 or tests, scoped to what that owner controls.
- **IMPLEMENTED, UNACCEPTED** = source or ZIP exists, but no browser proof.
- **PRESENTATION** = visible/read-only, not force, matter, chemistry or progression.
- **PROPOSED** = a law/feature described in documents, not wired into runtime.
- **HISTORICAL** = HC build archive or older LS1 tests; do not delete or treat as current authority merely by age.

## C. Mandatory shared grammar (lock before future features)

| Stage | Owner | Question HUD must answer | Invalid claim to reject |
|---|---|---|---|
| **INTENT** | Input + VerbComposition | Which verb/chord was requested? | Button pressed = accepted action |
| **FOCUS** | Targeting / relationship | What is selected, eligible and in reach? | A nearby visual equals target acquisition |
| **RESPONSE** | Regional or physical owner | What was actually accepted, rejected, braced, moved or read? | Local site pulse = Silt physical grain push |
| **CONSEQUENCE** | Material ledger / local site / Host ledger | What changed, who owns it and for how long? | Visual wave = physical arrival or Host receipt |
| **INTERPRETATION** | Guide / HUD / audio | What does that change mean for the organism? | Lore invented as numerical credit |

Universal verbs: ▽ Pulse = project / listen, △ Absorb = draw / select, ◇ Stabilize = hold / regulate. A = interact/observe/commit. Chords remain combinations of the three, not fourth–eighth invented verbs. Flux = **local strain**; Form = **local imprint**; Void = **local trace**; Between = **a connection carrying a response**, not a quantity of matter.

**Do not confuse the three triads:** organ functions / 3 player verbs / 3 site measurements. The 3→6→12 phase engine is a related but distinct structural resolution scheme.

## D. Numerical/lore pathway — constrain equations before promoting them

1. **Current math: keep its ledger intact.** For each positive C0E2-B local impulse `delta`, account for source retention + transmissions + dissipation, limited by 0–1 capacity. Negative changes and C0E3 relief are accounted separately. Silt material uses its own conserved IDs/owners.
2. **Future Between trial (isolated, not live):** propose `B_ij = q_region * A_ij * P_ij`, where `A_ij` drops with tension mismatch and Form disagreement, and `P_ij` represents destination capacity/permeability. Normalize outgoing weights; never multiply matter into existence. Compare against the current q shares before integration.
3. **Memory is earned.** Local Form isn't genuine interregional Grave history. History-dependent `M_i` must come only from verified Host/Grave ledgers, survive legitimate revisit within runtime, and never run while its cell is unmounted.
4. **3/6/12 must have a cost curve.** A phase count can be forced via debug O or unlocked by return history today; neither proves physiological stability. Trial states: REQUESTED → PREPARING → SUSTAINED / STRAINED → FALLBACK. Compare 3/6/12 under identical load and material states. Do **not** assume 12 is strictly better.
5. **Readable consequence:** whenever a state changes, render a corresponding deformation/delay/texture/audio response and state name, or explicitly mark the reading as diagnostic.
