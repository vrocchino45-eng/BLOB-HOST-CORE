## Functional connection

A mature Core that safely transferred Grave memory and actually returned from the route now uses that retained memory to help rebind disturbed Grave residue. The assist applies only to the existing recoil/trace recovery branch: residue already read and stabilized, within the existing range, with Stabilize held. It does not speed the initial stabilization or safe-memory transfer.

The earned source uses the existing maximum recovery assist: **×1.15** baseline recoil reduction and trace restoration rates. Authenticated Host/Vascular memory retains its existing pressure-dependent rate. The stronger source wins; they never add or multiply together. The combined factor cannot exceed ×1.15. This is a rate comparison, not a guarantee that a whole interaction takes 15% less time.

| State | Result |
|---|---|
| Debug pieces, visits, immature Core, incomplete safe transfer or no return | No earned assistance |
| Mature Core plus committed imprint, safe transfer and return | Earned source available, independent of collecting all three pieces |
| Eligible damaged residue and held Stabilize | Existing recoil and trace recovery can run at ×1.15 |
| No read, initial stabilization, wrong distance, wrong verb or released hold | No earned recovery action |
| Inspection or Core Work | Earned Core assist suspended; prior baseline/Host recovery behavior retained |
| Off-route | Grave owner remains dormant; no remote repair or catch-up |
| Concurrent authenticated world memory | Stronger source within the same ceiling; no stacking |

Damage, protected-remains resistance, risk thresholds, safe-transfer duration, recipe values, material ownership and route/phase credit rules remain unchanged. Recovering a disturbed trace sooner can make an existing safe condition readable sooner; it does not bypass that condition. Repeated returns do not increase the factor. No save system is added.

The existing recovery visual follows the actual trace/recoil change. Both compact Core labels and detailed notes explain the earned Grave cause and limits, including when only one regional piece exists. The local Grave explanation distinguishes this from arrangement physiology and Vascular idle recovery.
