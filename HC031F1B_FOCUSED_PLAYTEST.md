# HC031F1B Focused Playtest

Use **Shift+1** to start just outside the Host Contact Shelf in Surface Wake.

Spend about 5–8 minutes on the shelf. The important test is not completion; there is no objective or gate here.

1. Approach the broad teal membrane bed and confirm tendrils attach only when you are physically near it.
2. Move across the soft sloped tissue and watch whether the body stays outside the visible surface while the gait continues.
3. Reach the darker scar brace and compare how firmly it carries the same tendril pull.
4. Move onto the brown residue patch and look for weaker/slower traction rather than a new movement mode.
5. Pass close to the faint connective lip. It should remain visible but **must not** become the Core's surface truth or receive suction pads.
6. Stop input on each valid surface and confirm the Core settles instead of skating.
7. Leave the shelf. Outside registered surfaces the old authored movement envelope should safely take over; random translucent/decorative meshes should not acquire suction.

### Acceptance questions

- Can you visually tell which pieces of Host anatomy are usable rather than everything being sticky?
- Does the same tendril language remain intact across all four materials?
- Does scar feel like a better brace than residue without feeling like a different control scheme?
- Does the Core stay clearly outside the actual visible surface?
- Does the intentionally non-crawlable connective lip remain non-interactive?

Anchored Pulse is deliberately not part of this build. This pass prepares the surface load/transmission data required for that next proof.
