# HC028J Focused Playtest — Entity Relationship Grammar

## Goal
Determine whether the Tender and Watcher now feel like different living systems interpreting the same Core gestures, without making the player think a new combat/combo/progression system was added.

## Test A — same single verbs, different organisms
In Surface Wake, get close enough to clearly see both organisms and separately use the existing Pulse, Absorb and Stabilize verbs.

Expected:
- Pulse reads as an offered/probing signal.
- Absorb makes the Tender cup/guard while the Watcher retracts/samples more cautiously.
- Stabilize settles both, but the Tender should feel receptive while the Watcher feels anchored/observational.
- No new prompt, reward, damage or gate appears.

## Test B — paired relationships
Try the three existing two-verb relationships near each organism:
- Stabilize + Pulse
- Stabilize + Absorb
- Pulse + Absorb

Expected:
- The response is visibly different from merely stacking two unrelated effects.
- Tender reads more relational/care-oriented.
- Watcher reads more sensing/guarded.
- Pulse + Absorb should be the clearest contrast: Tender exchange versus Watcher counter-sensing.

## Test C — bond context
If the Tender bond has already been earned, compare Stabilize + Absorb and Pulse + Absorb before/after or against an unbonded fresh run if convenient.

Expected:
- Existing bond changes the *interpretation/read* of those gestures.
- HC028J must not create, accelerate or revoke the bond itself.
- Tender repair rate remains exactly as before.

## Test D — full-system chord
Use all three verbs together near the organisms.

Expected:
- Tender reads as a whole-Core display/attunement.
- Watcher reads as full-spectrum sensing.
- It should feel rare/rich, not like a super attack.

## Test E — bonded Tender across regions
Carry the already-bonded Tender into a contrasting region.

Expected:
- HC028I regional entrainment is still visible.
- HC028J player relationship gestures layer on top rather than replacing the regional identity.
- The Tender remains a companion/care organism, not a route guide or combat pet.

## Regression checks
- Comb can still be entered, departed, returned from and re-entered after HC028I1.
- Watcher remains nursery-bound.
- Tender bond/repair behavior is unchanged.
- No entity root teleports or gains new navigation authority.
- No new input, HUD instruction, health bar or affinity meter appears.
- HC028G verb/lift visuals and HC028H/H1/H2 topology behaviors remain unchanged.

## Pass condition
Pass if you can begin to read **"what kind of organism is this?" from how it answers the same Core chord**, while still feeling that Pulse / Absorb / Stabilize are one universal physical language rather than bespoke NPC interaction buttons.
