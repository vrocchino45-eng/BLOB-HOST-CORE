# HC027G1 Focused Playtest — Eight-Minute Platform Run

## Setup
1. Run the project from VS Code as usual.
2. Play in an external Chrome/Edge browser window.
3. Click once in the game so browser audio is unlocked.
4. Use **Shift+1..8** to move between test platforms.
5. Advance manually. The ~60-second windows are suggestions, not timers.

## Eight-minute itinerary

### Minute 1 — Shift+1: Orientation / Surface Wake
Check:
- basic movement/camera
- approved normal audio level
- first Pulse clarity
- whether the space is immediately readable

### Minute 2 — Shift+2: Pressure / Guide Threshold
Check:
- camera-relative movement under pressure/current
- Pulse and Stabilize readability
- whether pressure feels environmental rather than like invisible walls

### Minute 3 — Shift+3: Inquiry / Hub Core Work
The existing debug retained anatomy is seeded automatically.
Check:
- entering/using Core Work
- selected anatomy hierarchy
- Deep / Inner / Membrane placement readability
- whether surrounding Host material properly recedes in close view

### Minute 4 — Shift+4: Memory / Grave Reply
Check:
- Pulse return timing
- scar/memory material reply
- temporary answer memory
- consequence timing

### Minute 5 — Shift+5: Flow / Vascular Physiology
Retained anatomy is seeded automatically.
Check:
- boost/endurance feel
- Deep-vs-Membrane physiological contrast
- current traversal and cadence

### Minute 6 — Shift+6: Pressure / Silt Intake
Check:
- Absorb intake/flow/capture language
- resistance
- recovery after pressure

### Minute 7 — Shift+7: Coherence / Comb Threshold
Check:
- Stabilize convergence/lock
- mixed information readability
- whether threshold space suggests coherent movement without a waypoint

### Minute 8 — Shift+8: Open Inquiry / Signal Plain
Only the local existing Signal Plain encounter is reset.
Check:
- open-field orientation
- Pulse inquiry at larger spacing
- Host answer memory/material responses
- whether the world creates curiosity without directing you like a waypoint

## What the harness should NOT do
- no automatic jump after 60 seconds
- no progression advancement
- no objective completion
- no route-history changes
- no gate unlocks
- no gameplay stat changes

## Useful use patterns
You do not have to perform the full eight-minute itinerary every time.
- Need Core Work? Press Shift+3.
- Need physiology? Shift+5.
- Need sonar/material response? Shift+4 or Shift+8.
- Need threshold/Stabilize? Shift+7.

The harness exists to reduce repetition, not prescribe how long you must test each system.
