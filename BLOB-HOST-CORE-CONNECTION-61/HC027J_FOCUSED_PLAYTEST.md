# HC027J Focused Playtest — Persistent Local Consequence

## Duration
About **3–5 minutes**.

## Setup
1. Open the external browser build.
2. Keep the HC027D1 listening level where it already feels comfortable.
3. Use **Shift+8** to enter Signal Plain.
4. Hide/ignore debug information while judging the world itself; use debug only if something is unclear.

## Test A — Persistent aftermath
Choose one condition and use the plausible matching experiment:
- draw/release → Absorb
- call/wait → Pulse
- phase-slip → Stabilize

After the response triggers:
1. **stop using the verb**
2. move several units away
3. wait at least 8–12 seconds
4. look/listen again

### Pass question
Can you still tell that this local condition is different because of what you did?

## Test B — Compare two changed conditions
Change a second receptor before the first one fully decays.

### Pass question
Do the two altered areas remain distinguishable, rather than reading as one generic “activated” effect?

## Test C — Wrong experiment
Try a clearly different verb at a receptor.

### Pass question
Does it remain harmless and avoid producing the long persistent aftermath, without giving an error/checkmark/failure message?

## Test D — Natural decay
Ignore a changed receptor long enough for it to recover.

### Pass question
Does the world return to baseline naturally rather than feeling like a timed UI state expiring?

## Acceptance target
Without relying on the debug HUD, the player should be able to recognize **which receptor changed and how it changed** for at least ~10 seconds after input stops.

## Deliberate non-test
Do **not** expect the changed condition to point toward another receptor or reveal the next destination. That relationship belongs to **HC027K — Consequence Creates Next Question**.
