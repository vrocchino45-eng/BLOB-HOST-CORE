# HC027F Focused Playtest — Host Answer Memory / Traversal Inquiry

Target duration: **5–7 minutes**. Keep the HC027D1 listening level unchanged.

## A. Basic memory — 1 minute
1. Move into an area with several things Pulse can answer.
2. Fire one Pulse.
3. Let the return(s) arrive.
4. Do not immediately Pulse again.

Look for a returned area remaining subtly legible after the echo reaches the Core.

Question: can you tell that **the world answered from a place**, rather than only hearing an abstract sound?

## B. Approach — 1–2 minutes
Choose one answer and move toward it.

Expected:
- existing Host material becomes somewhat more organized/local around the remembered area
- there is no arrow, icon, beam, waypoint or forced camera
- ignoring the answer remains completely valid

Question: does it feel like following evidence, or like following a waypoint? We want **evidence**.

## C. Local read — about 1 minute
When close to a remembered answer and not standing on another authored interaction target, use Scan/Interact.

Expected:
- a brief local material response/read
- no reward, inventory, completion percentage or gate change

## D. Let it fade — about 30 seconds
Pulse once, receive an answer, then ignore it.

Expected: the memory fades naturally after several seconds and leaves no persistent marker.

## E. Normal traversal — 2 minutes
Move normally and use Pulse only when curious.

Main question:
Does traversal now begin to support:

**see space → wonder → Pulse → hear/see answer → choose whether to investigate → learn something local → continue**

without making Pulse feel mandatory every few seconds?
