# HC027J1 Focused Playtest

Use **Shift+8** first. Hide the debug HUD for the main readability judgment, then turn it back on only if something is ambiguous.

## 1. Quick Pulse
Tap and release X quickly. It should feel crisp and local. The answer should appear attached to an actual nearby Host surface/object rather than as a floating destination. Ask: **does this feel like something I can plausibly approach now?**

## 2. Charged Pulse
Hold X for roughly 0.8–1.2 seconds, then release. The Core should visibly compress/gather before a much stronger outward release. Ask: **could I identify the charging state without a meter or HUD?**

## 3. Local versus deep return
Try the charged Pulse where farther Host structure is present. A deep answer should be broader, softer and ghostlier than a local return. Ask: **can I tell “near/actionable” from “deeper structural information” without mistaking the latter for a waypoint?**

## 4. Recovery
After a charged release, stop input briefly. The Core should visibly ring/recover for a short period. It should communicate “I pushed this function harder” without a cooldown banner.

## 5. Absorb
Hold Absorb near valid material. Look for a stronger directional intake/funnel and Core intake-biased silhouette. It should read as sustained commitment, not a static beam.

## 6. Stabilize
Hold Stabilize around instability. Look for cleaner Core symmetry, three-axis target coherence and a stronger regulation tether. It should read as imposing order rather than simply activating the third effect.

## Acceptance
With HUD hidden, the playtest should make **prepare → action/travel → Host answer → recovery** readable, and quick/local Pulse answers should feel materially reachable while charged/deep answers feel intentionally structural rather than accidentally unreachable.
