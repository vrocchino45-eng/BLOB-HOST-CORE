## Selected gap and duplication check

The candidate edge is **existing Core coherence → Vascular directional calming strength**. It is deliberately distinct from Core movement reception: Vascular owns the current it generates; movement owns how the Core receives it. Both effects already have individual places in the pipeline.

Other existing modifiers matter: PlayerMovementController also applies a verb environmental-flow multiplier, growth/route coupling, pressure and fluid-slip damping. The next model must measure the combined chain, not merely show a new local scalar changes. A useful local difference is insufficient if it makes total stabilization excessive or navigation worse.

Registry scheduling currently publishes the radial profile after regional/movement consumers; consumers can therefore use the prior published profile. Preserve that established ordering and measure the one-frame placement/mode transition. Do not reorder the registry to make a test appear same-frame.
