# HC027D1 Focused Audio Reference Playtest

Target length: **2–3 minutes**. No long recording required yet.

## Setup
- use the same speakers/headphones used for the HC027D test
- system/output volume: **65%** as the first reference point
- external Chrome/Edge preferred
- click once to clear AUDIO LOCKED before controller-only play

## A. Normal distance
Stay in ordinary zoomed-out play for 20–30 seconds.

PASS target:
- sound is comfortably noticeable without concentrating on it
- it is not so loud that you immediately want to lower system volume

## B. Close Core
Move into the close/Core view.

PASS target:
- clear increase in intimacy/presence
- not a giant loudness jump
- Core detail becomes easier to hear than at normal distance

## C. Pulse dynamic hierarchy
Trigger Pulse near and farther from answering material.

PASS target:
- emission is obvious
- nearby return is clear
- farther return is quieter but still readable when within the current sonar range
- return timing still reads as distance

## D. Absorb / Stabilize
Use one valid Absorb and one Stabilize cycle.

PASS target:
- both are as readable as Pulse at the same system volume
- neither requires changing volume

## E. Report four things
1. At 65%, is ordinary zoomed-out play **too quiet / comfortable / too loud**?
2. Is close view **too quiet / comfortable / too loud**?
3. Which family is loudest: **Core / Verbs / World / Ambience**?
4. Roughly what system volume feels like the best everyday BLOB level now?
