# HC027L1 Focused Playtest — Rhythm Compression & Grammar Reinforcement

## Recommended run
Use **F1 Playtest Trace** and play normally for **8–10 minutes**. Do not try to prove every system. Let repetition happen naturally.

## What to watch

### Repeated sonar
If the same deep answer attracts you more than once, notice whether the second/third read feels like new information rather than the same unreachable ping.

Desired progression:
- first read: something is there,
- second read: there are layers / intervening volume,
- third read: this is structural information, not an immediate target.

### Dense Pulse moments
After a charged/deep Pulse, ask whether the world gets enough time to resolve before unrelated information becomes important again. F1 shows the active reorientation duration.

### Vascular middle
Play through it normally. Do not hunt for three invisible checkpoints. The route should naturally vary its existing motion language so the middle feels like several meaningful situations rather than one long visual sentence.

Desired reads are roughly: uncertain/probe → loose draw/release → phase strain/coherence. No HUD prompt should prescribe Pulse/Absorb/Stabilize.

### Repetition
Look for the rule:
**first exposure = notice → second = recognize → third = variation/resolution.**
If a fourth exposure still feels identical, note the time.

### Density
Call out two different failures separately:
- **visual overload:** too many things demand the eye,
- **semantic stagnation:** lots of movement/geometry, but your understanding/question is not changing.

## F1 telemetry additions
- `Sonar ... res N/3 ...`
- `Rhythm ... reorient Ns ...`
- `Semantic ... repeats ... STAGNANT/changing`
- `Grammar ...` (debug-only Vascular reinforcement state)

## Acceptance
HC027L1 is a pass if the run has fewer identical repeated answers, committed moments breathe longer when needed, the vascular middle contains more distinct readable situations without new tutorial content, and deep sonar becomes less likely to feel like a broken/unreachable objective.
