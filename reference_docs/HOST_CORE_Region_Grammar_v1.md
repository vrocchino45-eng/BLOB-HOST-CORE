# HOST CORE Region Grammar v1

## 19. Region Construction Grammar

A BLOB region is a living host-space built from reusable spatial organs:

```text
anchor -> boundary -> route -> obstacle -> resource -> entity -> orbiter -> gate -> consequence
```

Every region should answer:

```text
What host function is this?
What movement shape does it use?
What chemistry does it teach?
What entities live here?
What ability does it ask for?
What can go wrong?
What changes after the player acts?
Where does the player go next?
```

### Core Region Parts

| Part | Function |
|---|---|
| Anchor | central readable orientation point |
| Boundary | playable limit that looks like what it does |
| Route | path the player can understand and follow |
| Obstacle | object that asks for a verb |
| Resource | nutrient/material/relic/byproduct to absorb/use/protect |
| Entity | living actor with food/fear/function/failure |
| Orbiter Presence | relationship/interpreter/ability source |
| Gate / Threshold | transition that changes state, not just location |
| Consequence Layer | world remembers what the player did |

## 20. Region Layout Archetypes

| Archetype | Use | Shape |
|---|---|---|
| Nursery Pocket | Surface Wake, bloom nurseries | small enclosed space, central anchor, one nutrient, one seam |

| Hub Junction | Hub Chamber, crossroads | central anchor, 3-5 route spokes, route identity markers |
| Route Chamber | Vascular, Silt, Graveyard | mechanic path, local objective, ability test, exit seam |

| Confluence Organ | late Act 4 | overlapping route grammars, mediation anchor, host-thread structures |

## 21. Act and Region Progression

### Act 1 - Interior Awakening / Host Nursery Band

Question: Can I become coherent enough to survive inside a living world?

Key regions:

- Surface Wake: nursery membrane, first movement/pulse/absorb
- Guide Threshold: living route organ, scan/stabilize/cross
- Hub Chamber: internal junction, first branching route identity
- Vascular Route: circulation, rhythm, charge, flow
- Silt/Burrow Route: appetite, pressure, compression
- Graveyard Chamber: memory, failed cores, relic residue
- Bloom/Charge/Shell pockets: focused mechanic lessons
- Comb Threshold: Act 1 proof gate
- Aperture Fields: first open ecology

### Act 2 - Host Ecology / Field Band

Question: How do my actions affect living systems larger than me?

Key regions:

- Arrival Shelf Fields
- Signal Plains
- Membrane Ridges
- Gathering Grounds
- Bloom Storm Basin
- Charge Span
- Grave Expanse
- Host Route Overlook
- Helix Vista

### Act 3 - Tonal Inversion / Strand B

Question: What if everything I learned was true, but only from one side?

Visual rule: triangle/square geometry, counter-clockwise motion, mirrored parallax, inverted assumptions.

Key regions:

- Inverted Shelf
- B-Strand Threshold
- Inorganic Ocean Strings
- Worker Tendril Route
- Shadow Host Basin
- Seed Exchange Chamber
- Reverse Threshold Organ
- Mirrored Aperture
- Octave Spine

### Act 4 - Host-Scale / Beyond Ecology / Integration

Question: What kind of living world can I help hold?

Key regions:

- Twin Strand Confluence
- Octave Lattice
- Core Choir Fields
- Beyond Shell
- Great Host Interior
- Final Integration Route

## 22. First Slice Reframed

The first playable slice is:

```text
Surface Wake -> Guide Threshold -> Hub Chamber
```

### Surface Wake

Meaning: first conscious awakening inside a Host nursery layer.  
Gameplay: movement, pulse, absorb, first nutrient, Guide tether, exit seam.  
World truth: safety is inherited, but not guaranteed.

### Guide Threshold

Meaning: first living route organ that tests whether the player can read passage intent.  
Gameplay: scan/tune, stabilize, pressure/current, crossing.  
World truth: a threshold is not a door; it changes the one who crosses.

### Hub Chamber

Meaning: first internal Host junction where the player realizes the world has authored routes and competing interpretations.  
Gameplay: branching paths, three visible gates, one active route, first memory fragment, first status page use.  
World truth: choice creates self-reading.
