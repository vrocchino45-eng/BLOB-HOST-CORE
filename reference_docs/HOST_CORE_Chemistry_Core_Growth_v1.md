# HOST CORE Chemistry Core Growth v1

## 05. Chemistry as World Interaction

The chemistry workbook is the interaction bible. Chemistry defines how regions behave, nutrients feed growth, materials carry world states, abilities interact with matter, entities feed/mutate/stabilize, orbiters interpret and guide, routes collapse or repair, Hosts metabolize and reseed, and the player identity path forms.

Every playable object should be defined by:

```text
Substance -> State -> Verb -> Reaction -> Risk -> Recovery -> Meaning
```

A nutrient is not just a pickup. A membrane is not just a wall. An entity is not just an enemy. A route is not just a level connection.

## 08. Core Definition System

A Core is not merely the player avatar. It is the player's body, class system, growth tree, chemistry filter, visual identity, story identity, and eventual host-capable seed.

A Core is shaped by nutrients absorbed, entities interacted with, orbiters bonded, abilities used, regions completed, failures survived, repairs performed, relics interpreted, routes chosen, and imbalances corrected or tolerated.

In short:

```text
Core = player body + player build + player history + player worldview
```

## 10. Base Core Abilities

### Pulse

Pulse is outward assertion of self. It exposes, repels, stuns, activates, ruptures fragile matter, and later travels through route structures.

Growth ladder:

```text
Pulse Flicker -> Pulse Burst -> Pressure Pulse -> Resonant Pulse -> Rupture Wave -> Host-Scale Pulse
```

### Absorb

Absorb is taking the world into self. It gathers nutrients and loose matter, but also shapes the core's chemistry and identity.

Growth ladder:

```text
Soft Draw -> Nutrient Pull -> Selective Absorb -> Entity-Safe Draw -> Relic Condensation -> Host-Thread Intake
```

### Stabilize

Stabilize holds coherence under pressure. It resists current, braces in threshold glow, and later anchors route/host systems.

Growth ladder:

```text
Hold -> Brace -> Living Brace -> Route Anchor -> Host Anchor
```

### Guide Scan / Sense

Guide Scan is the core learning to read the world. At first it is guided by the Guide orbiter. Later it becomes a core sense that reads seams, routes, entities, chemistry states, and false guidance.

## 14. Entities and Core Growth

Entities shape the core differently from nutrients. Nutrients are absorbed directly; entities are observed, avoided, weakened, helped, harvested, bonded, freed, corrupted, or protected.

Every entity should have:

```text
food + fear + function + failure state
```

Example:

```text
Spore Grazer
Food: loose Spore Milk
Fear: sharp Pulse bursts
Function: keeps Surface Wake clean
Failure: bloom clog if overfed
Player lesson: not every living thing is enemy
```
