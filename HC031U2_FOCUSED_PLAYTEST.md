# HC031U2 Focused Playtest — Persistent Living Ecology

## Purpose

Determine whether Gathering Ground now feels like an ongoing local ecology instead of six one-shot checklist events.

## Apply

Apply HC031U2 directly over **HC031U1**.

## Focused run

1. Reload normally and verify build identity **HC-031U2**.
2. `Shift+8` → complete the existing Ridge / Gathering Ground entry path exactly as before.
3. On first local entry, do **nothing for about 8–12 seconds**. Watch the Watcher and relay exchange before using verbs.
4. Approach the Watcher and try **Stabilize + Pulse**. Hold the relationship long enough to see the response develop; do not mash the chord.
5. Release, move away, then return later and try the Watcher again. The second answer should be a recurrence, not a new encounter identity.
6. Approach a relay and try **Stabilize + Absorb**. Hold long enough for the response phase to resolve.
7. Move back toward the Ridge while a response/cross-territory effect is active, then return to Gathering Ground.
8. Spend at least another minute wandering and using verbs naturally after `LIFE 6/6`.
9. Export with **Shift+T**.

## What to watch

- `LIFE` remains the initial 6/6 encounter-read count.
- `LOOP` increases when an already-understood relationship answers again.
- `MEM` settles toward `quiet_observer`, `coherent`, or `guarded` based on behavior.
- Reactive responses take time; they should not start and complete on the same instant.
- Breaking a response should visibly interrupt it rather than award completion for free.
- Repeated activity after 6/6 should still produce readable Watcher/relay/Ridge/matter behavior.
- Backtracking must not reset the accepted T6 continuity or the local ecology state.

## Acceptance

U2 is ready to lock only if the first six reads stop feeling like the end of the territory and recurrent behavior remains understandable without relying on the debug counters.
