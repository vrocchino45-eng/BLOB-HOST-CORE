# HC031I Build Report — Host Contact Ecology Continuation

Parent: **HC031H3 — Brace Continuity (merged/accepted foundation)**

## Purpose
Turn the proven tendril/contact/brace architecture into actual Host ecology rather than another mechanical test shelf.

HC031I extends Surface Wake's Host Contact Shelf into three linked material conditions that remain traversable with the existing controls:

1. **Living membrane path** — broad, forgiving crawlable tissue that visibly carries/recover around suction locomotion.
2. **Scar load buttress** — dense Host anatomy that visibly bears and concentrates Stabilized Projection recoil.
3. **Residue yield field** — weak material that accepts temporary suction but visibly slumps under traversal/recoil; Stabilize alone can temporarily cohere its presentation.

## Governing law
`same body grammar -> different Host material answer`

The player does not unlock a new ability and does not solve a hidden anchor puzzle. Membrane, scar, and residue are different substrates for the already-locked H3 body grammar.

## Runtime changes
- Expanded `HostContactShelfSystem` from four authored contact surfaces to a ten-surface continuation while preserving the existing surface-profile authority.
- Added `HostContactEcologyContinuationSystem` as a presentation/bounded-local-ecology consumer after Stabilized Projection.
- Added non-contact response shells so the Host can visibly answer without adding motion to the new physical continuation meshes underneath planted anchors; the original entry shelf keeps its pre-existing subtle breathing.
- Added four decaying local-imprint channels for readability only: membrane carry, scar brace, residue yield, residue cohesion.
- Added session telemetry fields for active ecology surface/role/response and local imprint.

**membrane carries** -> **scar braces** -> **residue yields**
