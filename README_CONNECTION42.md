# CONNECTION42 — Core Work family readability

Install over CONNECTION41. Extract into the project root, keeping CONNECTION42_PATCH intact, then run:

```powershell
node .\APPLY_CONNECTION42.mjs --check
node .\APPLY_CONNECTION42.mjs
```

Reload. Existing controls, F4 labels, Shift+F4 detailed notes and F8 census retain their mappings. Exact originals remain in CONNECTION42_BACKUP; `node .\APPLY_CONNECTION42.mjs --restore` restores recognized originals and protects later edits.

## Visible changes

Core Work now uses the audited family accents consistently:

| Retained family | Editing color |
|---|---|
| Grave memory | Muted violet `#B9A0BD` |
| Vascular rhythm | Cyan `#78E3FF` |
| Silt pressure | Ochre `#C99D55` |
| Selected piece | Small neutral contour `#F1EBD8` at its authored visible-center anchor |

Selection no longer depends on washing a piece into a common warm color. The final editing palette preserves its family hue, maintains a readable minimum opacity and moderates emissive intensity. Existing anatomy, piece scaling, authored motion and zone meanings remain owned by the prior systems.

The outer membrane, inner mantle, nucleus, prow and rear lobe are quieter during Core Work. Engine gyroscope art and world verb graphics are hidden while editing; their logic and timers continue. Normal presentation returns when leaving Core Work. Inspection alone retains its normal presentation.

The override runs after camera material fading, which otherwise restores older opacity targets. Before the next embodiment update, prior material values and engine visibility are restored; changes do not accumulate into the next animation or persist as a new world palette. One reusable selection contour is allocated per embodiment, with no per-frame mesh allocation.

## Scope and locks

| Pass field | Scope |
|---|---|
| Mode | Visual Lock / bounded Core Work proof |
| Purpose | Read retained identities and selection without relying entirely on labels |
| Allowed scope | Two visual modules, Core embodiment restoration/init binding, final camera-composition binding, verb-group visibility and bot coverage |
| Locked systems | Piece placement and authored transforms, chemistry classification, physiology, repair, progression, input mapping, camera motion/zoom and audio |
| Delete / disable targets | Mask engine/verb graphics only while editing; retain owners and restore normal visibility on exit |
| Visual target | Violet / cyan / ochre identities, neutral selection, quieter surrounding Core layers |
| Acceptance | All family/zone/selection cases, exact restoration, no accumulated changes, live mode exits, label continuity |
| Regression | Complete quick suite, normal/trial live labels and interruption coverage, guarded installer, production build |

This is the first palette migration proof, scoped to Core Work. Hub/region palette unification and engine/world verb color reconciliation remain future passes. World scenery may still overlap the Core; this update does not globally fade regions or certify human visual comfort. Labels and detailed notes retain their previous explanations.
