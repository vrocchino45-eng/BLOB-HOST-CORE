# HC-028D2 Focused Playtest

Play normally; do not hunt for A interactions. The pass succeeds when the world keeps communicating without requiring generic confirmation.

## 1. Signal Plain / receptor interactions
Approach the three receptor conditions and use the verb their physical behavior suggests. A should not be needed to mark a receptor read. A receptor should become retained/read only when the world actually answers the relevant verb.

## 2. Ambient inquiry
Use Pulse around readable Host material. The outward Pulse should carry the inquiry/read behavior. Pressing A near ordinary material should do nothing rather than producing a scan.

## 3. Return traversal
For Grave, Vascular, Silt, Comb and Aperture returns, once the route/fold is genuinely resolved, enter the return fold. No second A confirmation should be required.

## 4. Core Work exception
Enter Core inspection, then use D-Pad Down / G for Core Work. A/E should still grab/place retained anatomy in Core Work. This is intentional and should feel different from generic world interaction.

## Acceptance
PASS if you stop thinking of A as an “interact with everything” button and normal reading/traversal continues naturally through movement and the three verbs.

FAIL if ordinary observation, scanning, or a completed return fold still seems to ask for A; if A accidentally triggers route progress; or if Core Work grab/place stops working.
