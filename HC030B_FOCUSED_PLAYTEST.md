# HC030B Focused Playtest — Material / Entity Response Personality

## Recommended duration

**15–20 minutes.** Do not exceed ~25 minutes for this checkpoint.

## Main question

> Without reading debug labels, do different kinds of matter/organisms now feel like they answer the same verbs in different ways?

## Test focus

### 1. Same verb, different matter

Find at least two visibly different ChemObjects and apply the same verb to each.

Watch for:

- membrane flex/rebound,
- fluid ripple/redirect,
- scar resistance/shear,
- signal phase/echo,
- seed compact/protective response,
- residue slump/scatter,
- bloom asymmetric growth pressure.

Do **not** judge whether one is stronger or better. Judge whether it feels like a different material.

### 2. Same state, different expression

When possible, push two objects toward `strained` or `unstable` using Pulse / resisted Absorb, then Stabilize them.

Ask:

- Does instability on membrane look different from instability on scar/fluid/signal?
- Does Stabilize make each material settle in its own way rather than into one generic animation?

### 3. Entity personality

Interact with existing organisms using the established verb language.

- Tender should read protective/supportive.
- Watcher should read sensory/anchored.
- Vascular Relay should read like a flow handoff structure: downstream opening, upstream cupping, synchronized vanes under Stabilize.

### 4. Composition still matters

Use LT+X, LT+RT, RT+X, and all three. Confirm that HC029C composition remains understandable and that HC030B personality changes the *answer*, not the button grammar.

### 5. Free-play finish

Spend the last 4–5 minutes playing normally. The key signal is whether you naturally begin choosing what to do partly because of **what kind of thing** you are touching, not just because of its distance or current state.

## Regression watch

Stop and note if any of these occur:

- targeting starts stealing relationships,
- a material personality changes HC030A state thresholds,
- Absorb completes obviously incompatible matter,
- entity response appears to create new navigation/combat behavior,
- excessive deformation makes the target unreadable,
- personality effects overwhelm the cleaner HC029 symbol grammar.

## Export

Export telemetry at the end. HC030B uses `blob.session.telemetry.v1.20` and should retain the full focused session with material/entity personality context.
