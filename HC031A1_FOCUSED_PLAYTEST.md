# HC-031A1 Focused Playtest

Run the normal route loop into Grave, return to Hub, then enter Grave a second time.

Judge four things:
1. **Activation:** within the first several seconds, does Grave II unmistakably feel like the same Grave structure grown/deepened rather than the unchanged first visit?
2. **Recognition:** are the old Grave landmarks still spatially recognizable?
3. **Exit safety:** leave Grave II before resolving all three second-phase resonances. The normal Grave→Hub fold must still work.
4. **Resonance:** if you stay, test Stabilize+Absorb on the silt, Stabilize+Pulse on the scar, and all three on the inheritance remnant. These should deepen phase-2 progression but must never trap you.

A 10–15 minute run is sufficient for this correction.
