# HC031F1 Focused Playtest — Attached Pull Prototype

## Test length

5–8 minutes. Do not do a full route run yet.

## What to test

1. Enter a surface-eligible area and let the Core attach.
2. Pause with no stick input. Confirm the Core settles instead of skating indefinitely.
3. Push steadily across a broad surface. Watch for repeated **seal → pull → peel/reach → reseal** cadence.
4. Reverse direction. The Core may hesitate briefly while an anchor replants, but it should recover without becoming stuck.
5. Try a sloped/curved portion of the same authored envelope. Confirm movement stays tangent rather than driving through the surface.
6. Pull away hard enough to trigger the existing release behavior and confirm free-space movement returns normally.

## Acceptance questions

- Does attached motion now feel generated by the tendrils rather than by a sphere sliding under them?
- Can you visually identify a leading/load-bearing anchor during movement?
- Does the slight traction dip during handoff feel organic rather than sluggish?
- Does the ~0.30 stand-off keep the Core readable beside the surface instead of buried in it?
- Does stopping input produce a believable suctioned rest?
- Are free-space controls unchanged?

## Known limits for this proof

- No authored edge-wrap solution yet.
- No guaranteed wall/ceiling traversal yet.
- Contact still uses the trusted authored movement envelope, not arbitrary visible meshes.
- Surface chemistry does not yet change adhesion strength/crawl style beyond the existing attachment eligibility.
- Individual tendrils are automatic; there is no manual limb control.
