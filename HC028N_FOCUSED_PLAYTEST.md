# HC-028N Focused Playtest — Ecological Residue / Local Host Memory

## Purpose
Prove that a meaningful Tender/Watcher interaction can leave a faint, temporary memory in the Host **after** the immediate organism response is over, without turning ecology into a reward, route, or affinity system.

## Test A — Tender care trace
1. In Surface Wake, form a meaningful safe Tender relationship such as Stabilize + Absorb long enough for the Tender to understand it.
2. Release the chord and watch the M1 sequence complete: organism first, local matter answer second.
3. Wait until the Tender's immediate retained response has faded.
4. Move several body-lengths away, then look back at the interaction site.

Expected: a faint, sparse breathing/gathering bias remains in the **place where the interaction happened**. It should not chase the Tender. It should be much quieter than the original M1 response.

## Test B — Watcher sample trace
Repeat with the Watcher using Stabilize + Absorb or Pulse + Absorb.

Expected: sampling leaves a tighter held imprint; counter-sensing leaves a weaker tangential/scanning echo. It should not look like the Tender's soft breathing afterimage.

## Test C — Leave and return
After creating a residue, leave the local cell briefly and return before roughly 20–45 seconds have passed.

Expected: the trace may still be present if its timer has not expired. It has continued decaying while you were away. There is no permanent save-state ecology.

## Regression checks
- Hub destination A/E flow unchanged.
- Comb entry/re-entry and proximity return unchanged.
- No startup `recipe is not defined` error.
- Tender bond/repair unchanged.
- Watcher remains anchored.
- Player movement, verbs, chemistry, targeting, routes, and objectives unchanged.
- No new HUD meter or affinity value appears.

## Success question
Can you leave an interaction and, a short while later, recognize **where something happened** without the residue reading like a collectible, waypoint, aura, or power-up?
