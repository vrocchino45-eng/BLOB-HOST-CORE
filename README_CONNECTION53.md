# CONNECTION53 — consolidated earned-growth review checkpoint

One installer collects CONNECTION44–52 over the CONNECTION43 family-palette checkpoint. It supports the known covered-file states from **CONNECTION43 through CONNECTION52**. The package contains 24 changed source/test files and uses the existing project and dependencies. Production gameplay remains CONNECTION50; the executable bot catalog remains CONNECTION52.

## Install

Extract into your project root with CONNECTION53_PATCH intact:

```powershell
node .\APPLY_CONNECTION53.mjs --check
node .\APPLY_CONNECTION53.mjs
```

The check reports the recognized starting checkpoint. You can go directly from a supported checkpoint to this package without applying the intermediate installers. Reload after installation.

The installer validates every covered file, payload and unchanged gameplay anchor before writing. It recognizes CRLF text without treating it as a gameplay edit. Unknown edits in covered files/anchors or an unrecognized mixture of checkpoints are refused. Unrelated files, prior installers, reports and backups are preserved.

Exact starting bytes are retained in CONNECTION53_BACKUP. Restore with:

```powershell
node .\APPLY_CONNECTION53.mjs --restore
```

Restore returns to the starting checkpoint rather than assuming a fixed previous version. Later unknown edits and damaged backups are protected. A complete final checkpoint is also safely recognized without an installation backup; in that situation there are no saved originals to restore.
