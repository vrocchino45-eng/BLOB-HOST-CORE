# HC-031N Focused Playtest — First Physical-Language Validation

Target session: **6–8 minutes**.

This is not a speed test and not a feature hunt. The question is whether the existing interaction stack already reads as one physical language — especially whether crawlable Host structure feels like functional anatomy the Core can temporarily operate through.

## One full chain

1. Notice a nearby object/body and deliberately aim at it until attention owns it.
2. Approach a crawlable Host surface and attach.
3. Travel along the surface long enough that crawling/tendril locomotion is clearly active.
4. While maintaining the relationship, use **Stabilize**, then combine it with **Pulse** or **Absorb**.
5. Watch what answers: the chosen target, the contacted Host anatomy, surrounding organisms/ecology, or some combination.
6. Deliberately peel away from the surface into free movement.
7. Fly clear, then land/attach again.
8. Re-establish an interaction and use a verb again.

Repeat once with a different verb combination if natural.

## Feel question

Do not force the drum-kit analogy. Just notice whether the surface feels like:

- generic geometry you happen to stand on, **or**
- a functional part of an older Host Core that changes how your Core's same three verbs are expressed.

The second reading can be subtle. We are looking for an emerging relationship, not a new amplifier mechanic.

## Regression watch

- Aim still owns the noun; verbs do not steal targets.
- Attachment remains K/K1-stable.
- Surface travel is not constricted.
- Stabilize/Pulse/Absorb preserve the L meanings.
- Deliberate peel remains immediate and readable.
- No new HUD lock-ring or button requirement appears.

## Export

Use **Shift+T** at the end.

Expected export identity:

- build: `HC-031N`
- telemetry: `blob.session.telemetry.v1.34`

The JSON should contain `validation.physical_language.*` events. A full successful sequence ends with `validation.physical_language.chain_completed`; an incomplete sequence is still useful because its last stage/reason tells us where the language stopped reading continuously.
