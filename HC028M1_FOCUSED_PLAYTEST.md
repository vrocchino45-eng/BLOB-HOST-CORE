# HC028M1 Focused Playtest — Ecological Consequence Readability

## Goal
Judge whether the existing ecology loop is now readable as a **sequence of causes**, not one simultaneous cloud of Core VFX + organism animation + regional matter.

## 1. Tender: active chord → release
1. Use the bonded Tender.
2. Hold an established safe relationship such as Stabilize + Absorb long enough for the organism to read it.
3. While still holding, watch the Tender and nearby matter.
4. Release the buttons and keep watching for 1–3 seconds.

Expected:
- while held, the **organism body** is the clearest response; local Host matter remains subordinate;
- after release, the local matter pocket becomes more obvious (`answering`);
- it then sustains around the Tender (`expressing`) after Core verb VFX have already cleared;
- later it loosens back into the region (`releasing`).

The response should not look like a reward burst or new aura attached to the Core.

## 2. Tender: care vs guarded
Compare retained care/reciprocity with a guarded/testing memory.

Expected:
- care forms a looser breathing/gathering pocket;
- guarded state creates a tighter, more damped/retracted pocket;
- the difference is visible in nearby Host matter without reading debug text.

## 3. Watcher: sample vs counter-sense
Compare Stabilize + Absorb with Pulse + Absorb.

Expected:
- sample forms a tight held pocket close to the Watcher;
- counter-sensing reads more tangential/scanning;
- Watcher stays anchored and does not gain route/combat behavior.

## 4. Camera/occlusion check
Repeat a close Tender or Watcher interaction near the large tissue that obscured the HC028M video.

Expected:
- eligible foreground tissue may soften/pull the camera back slightly when it blocks the Core→organism corridor;
- no snap, lock-on, forced orbit or new camera mode;
- normal traversal framing returns automatically as the ecological consequence fades or distance increases.

If the same occluder still fills the frame, note the exact region/object: the current accommodation only works on geometry already owned by the existing `CameraReadabilitySystem`/VisualComposer presentation set.

## 5. Regional inheritance
Try the same Tender relationship in two contrasting regions.

Expected:
- the causal order remains readable in both places;
- the organism-local pocket does not erase regional character;
- Vascular/Silt/Grave/etc. still shape those same motes through their existing physical grammar.

## 6. Regression
Confirm:
- launch has no `recipe is not defined` crash;
- Comb entry does not immediately eject and re-entry still works;
- Hub A/E route choice is unchanged;
- player/entity movement is unchanged;
- Tender bond/repair and Watcher anchoring are unchanged;
- P/A/S power/range/targeting are unchanged;
- no new HUD prompt or interaction button appears.

## Pass criteria
Pass if, without debug HUD, the player can plausibly perceive: **I acted → the organism answered → after I stopped, the nearby Host answered the organism → that consequence faded back into the place.**
