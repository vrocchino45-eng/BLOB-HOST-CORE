# HC-031D Focused Playtest — Rupture Consequence

Run 10–12 minutes. The test is consequence, not whether fragment capture still works.

1. In Grave II, rupture one object and intentionally collect nearly all fragments. Notice the region afterward.
2. Rupture another and deliberately leave most fragments behind. Stay nearby for 20–30 seconds.
3. Compare the Grave resonance response. Missed matter should settle and the corresponding regional landmark should subtly carry more of that material's character.
4. Leave and return if convenient. Residue should still read as history, but weaker than the fresh aftermath.
5. Confirm you can always leave and that no cleanup prompt/gate appears.

Primary question: **Does choosing what not to absorb leave a readable history in Grave without feeling like mandatory cleanup?**
