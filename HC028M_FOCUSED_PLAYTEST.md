# HC028M Focused Playtest — Reciprocal Ecology / Local Matter Coupling

## Goal
Judge whether relationship with an organism now feels like it belongs to the **Host around it**, rather than stopping at the organism's animation/AI response.

## 1. Tender — safe relationship
1. Earn/use the existing Tender bond.
2. Produce a relationship that resolves into retained care/reciprocity (for example Stabilize + Absorb in the established grammar).
3. Release the buttons and watch both Tender **and the nearby Host motes**.

Expected:
- Tender retains its HC028K/HC028L care response.
- nearby Host motes form a loose breathing/gathering pocket around the Tender for the remaining memory duration.
- no HUD marker, reward text, route change or player-force change.

## 2. Tender — guarded relationship
Create a guarded/testing relationship and release it.

Expected:
- Tender gives the existing HC028L protective spacing response.
- nearby material contracts/damps more than the care response instead of using the same animation with a different label.

## 3. Watcher — sample vs counter-sense
In Surface Wake compare:
- Stabilize + Absorb / contained sample,
- Pulse + Absorb / counter-sensing.

Expected:
- retained sample holds nearby material in a quieter local pocket;
- counter-sensing produces a more tangential/scanning ripple;
- Watcher itself remains anchored.

## 4. Same Tender relationship across places
If bonded, carry the Tender through at least two contrasting regions (Vascular vs Silt or Grave is ideal) and produce the same safe relationship.

Expected:
- the **relationship identity is recognizable**, but the matter response does not look copied between regions;
- Vascular current should keep carrying/stretching the local response;
- Silt should feel denser/compressed;
- Grave should feel more damped/retentive.

Do not expect a unique authored special effect per region; the point is shared physical laws acting on the same existing motes.

## 5. Regression
Confirm:
- normal player movement is unchanged;
- P/A/S power/range/targeting are unchanged;
- Tender repair/bond rules are unchanged;
- Watcher never leaves its nursery anchor;
- Hub deliberate A/E route choice still works;
- Comb entry does not immediately eject the player and re-entry still works;
- no `recipe is not defined` startup error.

## Pass criteria
Pass if the player can plausibly perceive: **"this organism's remembered state changed the nearby living material"** without reading debug HUD and without mistaking the response for a new power-up, waypoint or environmental force on the Core.
