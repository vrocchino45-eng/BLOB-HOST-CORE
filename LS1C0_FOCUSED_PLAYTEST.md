# LS1C0 — Quick Look Focused Playtest (5–8 minutes)

1. Start on the same LS1B build. Verify movement, targeting, Pulse, Absorb, Stabilize, F1/F2/F3 and existing status menu still work normally.
2. Press **F4**, or **hold LB+RB for about 0.6 s** on Xbox. Quick Look should appear bottom-right. Repeat to close. When the panel is open, normal simulation continues.
3. In Hub and then Silt, compare the panel's **region identity** with the area you see. If it names a cell unexpectedly, note exactly where and what the debug HUD calls it.
4. Point at or select a nearby object with existing targeting. Check whether the **Focus** label matches the real target. With no targeting lock, it must admit it does **not** use camera raycast.
5. In Silt, move from the pressure throat into Reservoir, Garden and Veins. Check the **LANDMARK** label changes; remember it resolves the nearest authored habitat rather than identifying every shape.
6. Start or revisit the yellow-porous-packet interaction. Open Quick Look and compare the displayed pressure stage and ledger counts as material moves, settles, grows and returns. Do not expect a full ecological completion description if the sequence has not happened.
7. Switch Core engine mode between 3/6/12 using your existing control. Verify Quick Look reports the live phase count and explicitly says this is **not** proof that Silt geology also uses a 3/6/12 layout.
8. Scroll the overlay to see **Implemented**, **Design Intent**, and **Playtest Questions**; test closing and reopening. Ensure it does not cover essential gameplay controls permanently.

### Feedback to return
A short video or note is enough: name a landmark in your own words (e.g. “two balls and four pyramids”), tell me whether Quick Look can identify it, whether the listed controls work, and what is visually missing. This remains a prototype—do not expect every object in every region to have an authored explanation yet.
