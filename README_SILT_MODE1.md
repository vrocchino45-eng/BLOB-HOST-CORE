## Install

Install the previously delivered SILT-II1 delta first. Extract this ZIP in the BLOB-HOST-CORE project root, then run in PowerShell:

```powershell
Expand-Archive -LiteralPath .\BLOB_SILT_MODE1_DELTA.zip -DestinationPath . -Force
node .\APPLY_SILT_MODE1.mjs
```

Reload the game. The installer verifies the exact SILT-II1 source and helper, verifies its payload, saves the original source, and refuses unknown edits. Repeat application is safe.

```powershell
node .\APPLY_SILT_MODE1.mjs --check
node .\APPLY_SILT_MODE1.mjs --restore
```

Restore reinstates the prior SILT-II1 file, provided the installed file and backup remain recognized. It refuses to overwrite later edits.
