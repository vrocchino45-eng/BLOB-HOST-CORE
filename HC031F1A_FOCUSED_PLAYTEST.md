# HC031F1A Focused Playtest — Surface Truth + Pull Readability

## Test length

4–6 minutes. Stay on one broad visible surface and one slope; do not test corners/ceilings yet.

## Test sequence

1. Approach a broad visible surface and attach.
2. Stop moving. Confirm the Core settles beside the visible mesh rather than sinking into it.
3. Hold one direction for ~5 seconds. Watch for a repeated sequence: **probe -> seal -> load -> body pull -> rear peel -> reseal**.
4. Pause again. The Core should remain visibly supported, not skate.
5. Reverse direction. There should be a short plant/handoff hesitation before movement re-establishes.
6. Repeat on a sloped surface.
7. Pull away and verify free-space movement returns normally.

## Acceptance questions

- Does the Core stay outside/alongside the surface you can actually see?
- Do the suction pads appear to be planted on that same surface?
- Can you identify which tendril is carrying the current pull?
- Does the Core visibly stretch/lean toward that anchor during the load window?
- When there is no useful forward anchor, does movement briefly hesitate rather than glide?
- Does repeated movement feel like tendril locomotion instead of a translated sphere with animated limbs?

## Still out of scope

No edge wrapping, no guaranteed wall/ceiling traversal, no material-specific adhesion, no manual limb control, no regional-history integration.
