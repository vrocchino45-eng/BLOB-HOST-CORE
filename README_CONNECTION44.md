## First functional earned adaptation

The growth chain now carries one retained world experience into continuing Core physiology:

**Nursery growth → mature Binding Core → completed Vascular cadence carried back → retained circulation → higher idle reserve recovery.**

| Condition | Result |
|---|---|
| Debug pieces, region visits, or an unfinished cadence | No adaptation |
| Mature Binding Core plus retained Vascular return with three cadence reads | Idle reserve recovery rate ×1.08 |
| Mature Core plus earned/returned Grave memory, Vascular rhythm and selective Silt pressure | Integrated Core stage and anatomical-phase recognition |

Maturing the initial Binding Core retains its existing requirements: player-authored nursery success and protected-seed integration. The Vascular return must already be recognized by CoreGrowthSystem. Repeating a return does not stack the multiplier. The adaptation persists across region changes within the existing running session; this update does not add a save system.

The 8% rate applies while the existing reserve system considers the Core idle. It does not increase reserve capacity, reduce held-action drain or directly add a repair/damage multiplier. Recovering reserve sooner can improve later actions through the existing fatigue law. In the all-Inner setup, one idle second from 20% reserve reaches 31.34% with earned circulation, versus 30.5% at the prior rate.

Integrated Core recognizes the existing three-organ coupling. Grave requires safe memory transfer and return; Vascular requires the retained cadence and return; Silt requires pressure/rib reading, safe matter, leaving dense matter intact and return. The stage itself grants no engine phase credit, route completion or new control. Existing 3→6→12 progression keeps its own prerequisites.
