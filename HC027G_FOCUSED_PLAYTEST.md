# HC027G Focused Playtest — Host Material Reply Grammar

Target: **5–8 minutes**. Keep the HC027D1 listening level unchanged.

## A. Pulse and approach
Pulse in several different-looking areas and let the returns arrive. Follow one remembered answer without immediately using Scan.

Question: does the returned area feel like it has a **kind of behavior**, not merely a location?

## B. Compare reply character
Try to encounter several response classes. Look for these broad impressions rather than exact animations:

- membrane — broad / wrapping
- seed — clustering / breathing
- scar — heavy / delayed / settling
- signal — coherent / rhythmic
- fluid — streaming / directional
- dense — compact / still
- living material — soft / irregular

Question: can you begin making a guess before the text read?

## C. Confirm with Scan
When close and no authored interaction target owns the button, Scan/Interact.

Expected: the text should **confirm or clarify** what the motion suggested, not provide the first and only clue.

## D. Ignore answers
Pulse once and ignore every answer.

Expected: memories still fade naturally; no class nags the player or becomes a waypoint.

## E. Normal traversal
Move for a few minutes using Pulse only when curious.

Main question:
Does the world now feel more like **different materials answering differently**, or does it still feel like one generic particle effect around several labels?
