**notice → choose → verb experiment → persistent consequence → another existing condition changes → new curiosity**

HC027K does not decide the player's next destination. It makes physical relationships legible enough that a new question can arise without an objective marker.

## Implemented

1. `redistributed_flow` → `afterflow_exposes_phase_slip` → receptor 3.

### 4. Presentation hierarchy

Primary attention becomes the **linked Host condition**; the source consequence remains secondary. Guide/unrelated effects yield while the relationship is readable, while ambient Host material remains available because it is carrying the relationship itself.

Multiple relationships can coexist. The latest successful consequence becomes primary to prevent equal-weight visual noise.
