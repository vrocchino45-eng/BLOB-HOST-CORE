# BLOB D11R + GSL-3 (parallel, isolated)

D11R: frame-level reconstruction of *modeled* away and hold gates from D11O owner samples. It does not change movement and cannot prove the owner's exact refusal condition.

GSL-3: standalone HTML expressing anticipation, hesitation, recoil, and settling while retaining GSL-1 timing. Silent; no live Guide connection.

## PowerShell from project root

```powershell
Expand-Archive -LiteralPath ".\BLOB_D11R_GSL3_PARALLEL_DELTA.zip" -DestinationPath "." -Force
py .\D11R_FRAME_RECONSTRUCTION.py .\1BOT1D11O_RESULTS.zip .\BOT1D11R_FRAME_RECONSTRUCTION.json
Start-Process ".\GSL3_EXPRESSIVE_LAB.html"
```

If you have only the extracted D11O results folder, replace the ZIP path with that folder path. Upload BOT1D11R_FRAME_RECONSTRUCTION.json. No new browser gameplay capture needed.
