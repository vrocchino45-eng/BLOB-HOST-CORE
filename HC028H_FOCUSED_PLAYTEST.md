# HC-028H Focused Playtest

## Goal
Confirm that changing retained Core anatomy in Core Work now changes **how the Core carries the same world rhythm**, without introducing a new HUD dependency or obvious buff-selection loop.

## Test A — Deep concentration
1. Enter Core Work.
2. Place all three retained anatomy pieces in Deep Core.
3. Leave Core Work and spend ~20 seconds in a strongly readable region such as Vascular or Silt.

Expected: the Core reads steadier/buffered; regional resonance should take less visual ownership immediately but should linger more calmly once established.

## Test B — Membrane saturation
1. Put all three retained pieces near the Membrane.
2. Return to the same region and move/play normally.

Expected: regional rhythm should appear to reach the Core faster and more visibly; firing response should feel sharper/more exposed. Do not expect a new route advantage or timing requirement.

## Test C — Inner saturation
Put all three pieces in Inner Body.

Expected: a controlled/transmission character between the Deep and Membrane extremes rather than a copy of either.

## Test D — 1:1:1 balance
Put one piece in each zone.

Expected: broadly adaptive/neutral embodiment, not an obviously superior build. It should remain recognizable as the same Core and same region.

## Test E — mixed 2:1 states
Try at least two 2:1 distributions.

Expected: they should read as blended personalities rather than binary presets. There should be no abrupt stat-mode UI or new button requirement.

## Regression checks
- Hub A route commit still works.
- Pulse / Absorb / Stabilize visuals from HC028G remain intact.
- Lift-field streamlines remain read-only.
- 3→6→12 still changes firing resolution independently of topology.
- No route completes differently because of topology.
- No new timing gate appears.

## Acceptance question
**Can you feel that you built a different kind of Core in the same world, without the game needing to tell you a percentage bonus?**
