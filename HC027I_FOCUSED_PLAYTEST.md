# HC027I Focused Playtest — Embodied Verb Affordance

Use **Shift+8**. About 2–4 minutes is enough.

## First rule
Do not start by trying every button on every receptor. Watch each condition first and ask what it appears to be doing or failing to do.

## What to test
### Slow breath / draw-release
Approach the broad breathing receptor. Does its inward draw make Absorb feel like a plausible experiment before text tells you anything? If you hold Absorb nearby, can you see that the draw briefly responds?

### Paired chirp / call-wait
Approach the fast paired receptor. Does its call-and-pause rhythm make you think about answering/probing it? If you Pulse nearby, is the transient answer visually legible?

### Shear drift / phase-slip
Approach the slipping receptor. Does it look unstable enough that Stabilize feels plausible? While Stabilize is held nearby, can you see the layers settle, then resume slipping after release?

## Acceptance questions
1. Did at least one condition suggest a verb without a button prompt?
2. Did matching the apparent condition produce a readable short response?
3. Did the response feel like acknowledgement rather than objective completion?
4. Could you still intentionally try another verb without punishment?
5. Is Stabilize more memorable than it was before?

## Failure modes
- **Too obvious / color-lock feeling:** response reads like a prescribed correct button.
- **Too weak:** you only discover the relationship by random button testing.
- **Too persistent:** local change survives long enough to feel like HC027J was implemented early.
- **Too textual:** Guide description teaches the solution instead of the world behavior.
