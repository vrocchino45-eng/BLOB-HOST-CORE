BLOB Connection 62 — read-only source difference diagnostic

1. Extract this ZIP directly into your BLOB-HOST-CORE project folder (same folder as package.json).
2. Double-click RUN_BLOB_C62_SOURCE_DIFF.bat.
3. Select the ORIGINAL BLOB-HOST-CORE-CONNECTION-61.zip when the file picker appears.
4. Upload C62_SOURCE_DIFF_RESULTS.zip from your BLOB project folder.

This tool reads the eight relevant files from the original ZIP and your working project.
It creates hashes and text diffs in a separate results directory. It never changes source files.
If Python is not installed or Tkinter is unavailable, the window will show an error.
The result archive may contain snippets of your project source; review before sharing elsewhere.
Historical tests and game files are not modified. No new gameplay validation is claimed.
