## Host meaning and ownership

The Wounded Nursery is a frayed, wounded/nurturing Host under authored predatory external pressure. Protective Form tissue modulates Flux/Signal circulation as the larger body tightens and recovers. This is an explicitly authored prototype episode, not simulated predatory-host AI, a complete lifecycle or another Core upgrade.

The existing Host recipe owns the optional episode profile. HostConditionSystem validates its numeric/timing bounds, reads the existing runtimeSeconds clock and publishes Host/anatomy identity, phase, amplitude and episode provenance. It never writes local physicalFeel, input, material or credits. It runs before the regional consumers.

Only the mounted VascularRhythmRouteSystem applies the local directional-flow factor and existing fold presentation. PlayerMovementController consumes physicalFeel as before. The consumer rejects missing, disabled, stale, foreign or out-of-bounds publications. Macro state can progress while Vascular is hidden; hidden local physics and visuals remain suspended. Remount reads current amplitude once, without replaying missed local impulses.

The anatomy tag vascular_routes identifies the blueprint's tissue domain and this specific regional consumer; this patch does not add a new anatomy region or claim that every blueprint anatomy has a runtime registry entry.

Silt receipt load, VascularSiltSignalReceiver recovery and applied-effect events remain separate and byte-unchanged. Host external pressure never writes into that receiver or mints a Silt/Vascular/Grave receipt. When both causes are present, their local flow factors compose once with separate provenance. No passive goal progress, credits or material are created.
