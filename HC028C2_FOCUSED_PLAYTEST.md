# HC028C2 Focused Playtest — Gyro Engine + Vascular Accents

## Purpose
Test the two corrections from the HC028C video and HC028C1 verbal phase-read report without mixing in new gameplay.

## Part A — Vascular meter
1. Enter Vascular and play normally. **Do not count 1-2-3-4 at first.**
2. Watch/listen for a repeating phrase rather than a generic pulse:
   - 1 = transmit / strongest outward event
   - 2 = catch / hold
   - 3 = receive / inward draw
   - 4 = settle / preparation
3. Confirm movement still feels essentially like HC028C; the beat must not become a new obstacle or timing gate.
4. Complete Vascular and confirm the resolved return fold remains obvious and movement-driven.

### Vascular acceptance
PASS if the area begins to feel like **four different functions inside one repeating phrase**, especially if beat 1 becomes intuitively recognizable without a HUD.

FAIL if:
- it still reads only as generic periodic blinking,
- it becomes a metronome/rhythm-game prompt,
- rhythmic force noticeably fights traversal,
- the return transition regresses.

## Part B — Core 3→6→12 engine
At normal camera distance, cycle `O` through 3 → 6 → 12 → 3.

Do not judge by counting dots. Judge the **engine motion**:

- **3-phase:** three large single firing positions; chunky impulses and visible precession.
- **6-phase:** each function gains an opposed mate; visibly more counterbalanced/smooth.
- **12-phase:** four positions per function; dense near-continuous/turbine-like firing.

Rotate, tumble, move vertically, and view the Core from several angles. The engine should remain understandable with **no permanent top/bottom**.

Hold Stabilize briefly in each architecture. It should visually reduce gyroscopic wobble/precession and read as increased coherence, without freezing the Core or being required for ordinary movement.

### Core acceptance
PASS if 3/6/12 can be described as **rough → counterbalanced → high-resolution/continuous** from motion alone.

FAIL if:
- it reads as a colored belt around the Core,
- one plane becomes an obvious equator/top-bottom reference,
- 6 and 12 only look like "more dots",
- 12 becomes visual noise,
- Stabilize makes the engine look frozen rather than coherent.
