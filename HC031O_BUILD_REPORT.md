# HC-031O — Host Continuation / First Route Legibility

Parent: **HC-031N2 — Reacquire Closure**

Mode: **convergence / route legibility**

## Purpose

Close the first larger-scale domino after K→N: the Core can already move, attach, peel, reacquire, aim, combine verbs, and produce target/Host/community answers. HC-031O makes that same language reveal the **existing** Surface Wake → Guide Threshold continuation instead of leaving the player in a closed test slice behind older tutorial-era prerequisites.

This pass does **not** add a region, gate, teleport, verb, movement rule, or new ecology interpreter.

## New opening law

The authored Listening Fold may become readable through either of two already-existing causal paths:

1. **Host relationship path**
   - Core is attached to authored Host support.
   - A coherent surface mode is sustained (`surface_brace`, `braced_project`, `braced_draw`, or `surface_equilibrium`).
   - An existing Tender/Watcher relationship is meaningfully engaged.
   - Existing reciprocal organism memory commits the gesture.
   - Existing local Host matter reaches an `answering` or `expressing` response.
   - `SurfaceWakeGameplaySystem` retains that evidence and reveals the existing Listening Fold.

2. **Existing material path**
   - Read/change the moving matter.
   - Produce the existing safe material outcome.
   - Existing `materialPassageOpen` reveals the same Listening Fold.

Neither `EntityRelationshipGrammarSystem`, `EntityReciprocalMemorySystem`, `EntityLocalMatterCouplingSystem`, nor telemetry gains route/progression authority. They remain evidence providers. `SurfaceWakeGameplaySystem` owns reveal invitation; `LocalCellMorphSystem` still owns crossing.

## Seed change

The safe seed is no longer required as hidden crossing permission once the Surface Wake language has been learned.

- Seed remains absorbable nourishment / chemistry support.
- The original seed/composition continuation path remains valid.
- If absorbed, seed provides a small +0.025 morph-rate support bonus.
- If not absorbed, a completed Listening Fold plus scar/signal pulse can still start the existing continuous morph.

## Existing route preserved

`CELL_MEMBRANE_NURSERY_001` → `CELL_SCAR_FLOW_FOLD_001`

`LocalCellMorphSystem` still:
- requires Surface Wake fold completion;
- requires visible scar/signal pressure;
- starts from a Pulse contacting/attempted under that pressure;
- blends chemistry, physical feel, visuals, and source/destination content;
- changes `activeCellId` only when the continuous morph completes;
- uses no door, fade, teleport, or branch menu.
