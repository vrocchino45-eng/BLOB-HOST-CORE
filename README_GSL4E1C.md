## Install
Extract changed files to the BLOB-HOST-CORE project root (where GSL4E1A_BoundedExplorer.mjs and GSL4E1B_Choreography.mjs already exist).

## Test

If not already running, `python -m http.server 8765`; open `http://localhost:8765/GSL4E1C_PREVIEW.html`.
