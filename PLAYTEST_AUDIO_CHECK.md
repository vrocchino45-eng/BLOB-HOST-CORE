# HC027D1 — Audio Reference Check

Use this before another long recording.

1. Use the same speakers/headphones as the HC027D test.
2. Set system/output volume to about **65%**.
3. Open localhost in external Chrome/Edge.
4. Clear the AUDIO LOCKED banner with a real click/key once.
5. Listen zoomed out for 20–30 seconds.
6. Zoom in and compare.
7. Trigger Pulse, Absorb, and Stabilize.

### Primary PASS
- zoomed-out audio is comfortably audible at ~65%
- zoomed-in audio is clearly fuller/louder but not excessive
- Pulse emission and returns read without max volume
- Absorb and Stabilize remain readable at the same setting

### If 65% is too loud
Good information: lower system volume until normal play is comfortable and report the approximate percentage. We now have enough bus control to reduce the correct layer rather than undoing all gains.

### If 65% is still too quiet
Do not max it and continue silently. Report whether **everything** is too quiet or only one family (Core / Verbs / World / Ambience). That determines whether the next adjustment belongs at master, bus, or spatial attenuation level.

### If live audio works but recording is silent
That remains a capture-device problem rather than a BLOB mix problem.
